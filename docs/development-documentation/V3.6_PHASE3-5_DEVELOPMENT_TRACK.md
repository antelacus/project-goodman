## 概述

V3.6 旨在消除代码重复，统一工具架构和 Agent Graph，提供更现代的交互体验。

核心目标：

1. **统一 Agent 架构**: 提取核心节点逻辑，统一工具注册表，构建单一 UnifiedAgentGraph。
2. **实时反馈**: 实现 WebSocket (或 SSE) 流式响应机制。
3. **统一 UI**: 实现单页应用式的对话界面，整合现有三个模块的功能。

**文件**: `src/lib/workflows/core/nodes/*.ts`

实现通用的、可复用的工作流节点：

- `loadMemoryNode` (`load-memory.ts`): 加载历史消息，支持 `initialMessageCount`。

## Bug 修复: 会话记忆问题 (2025-12-24)

### 问题描述
多轮对话中，AI 无法加载前一轮对话历史，每轮都创建新的会话。

### 根因分析
1. **`/api/chat/route.ts`**: `sessionId` 放在 `state.sessionId` 而非 `state.input.sessionId`
2. **`/api/chat/stream/route.ts`**:
   - 使用 `uuidv4()` 生成新 UUID，与数据库创建的 session ID 不一致
   - `finalOutput` 从 `generateResponse` 捕获时缺少 `agent.sessionId`

### 修复方案
1. **API Route 修复**: 将 `sessionId` 移至 `input` 对象内
2. **Stream Route 修复**:
   - 移除 `uuidv4()` 生成逻辑，让 `loadMemoryNode` 管理 session
   - 新增从 `loadMemory` 节点的 `on_chain_end` 事件中捕获 `sessionId`
   - 优先使用捕获的 `sessionId`，确保前后端一致

### 修改文件
- `src/app/api/chat/route.ts`
- `src/app/api/chat/stream/route.ts`
