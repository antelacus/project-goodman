## 概述

V3.3 智能文档系统实现跟踪。本版本将文档选择从"用户手动选择"升级为"AI 自动发现 + 用户可覆盖"模式，同时增强财务报告的章节感知能力。

## Phase A: 数据库与核心模块 ✅

**完成日期**: 2025-12-18

### A1: 数据库迁移 ✅

**文件**: `supabase/migrations/20251218000000_add_intelligent_search.sql`

Schema 变更:
- `document_chunks` 表新增字段:
  - `section_title TEXT` - 章节标题
  - `section_level INTEGER DEFAULT 0` - 章节层级
  - `section_path TEXT[]` - 章节路径数组
- `documents` 表新增字段:
  - `section_structure JSONB` - 文档章节结构
  - `structure_quality TEXT CHECK (...)` - 结构质量评级

新增 RPC 函数:
- `search_documents_hybrid` - 多路召回 + RRF 融合搜索
- `get_document_sections` - 获取文档章节列表

索引:
- `idx_chunks_section_title` (GIN) - 章节标题全文搜索
- `idx_chunks_section_path` (GIN) - 章节路径数组索引
- `idx_documents_type_year` - 文档类型+年份复合索引

### A2: 章节解析器 ✅

**文件**: `src/lib/section-parser.ts`

实现要点:
- 三层降级策略: TOC 检测 → 标题模式识别 → 基础分块
- 支持中文财务报告标题格式 (一、, （一）, 1., 等)
- 输出: `ParseResult { sections, quality, hasToc, method }`

### A3: 章节感知分块器 ✅

**文件**: `src/lib/section-aware-chunker.ts`

实现要点:
- 按章节边界分块，保持上下文完整性
- 每个 chunk 携带 `sectionTitle`, `sectionLevel`, `sectionPath`
- 支持自定义 chunk size 和 overlap

### A4: 混合搜索服务 ✅

**文件**: `src/lib/document-search.ts`

实现要点:
- 调用 `search_documents_hybrid` RPC 函数
- 支持过滤条件: year, docTypes
- 返回结果按 RRF Score 排序
- 将 RRF Score 映射到 0-100 相关度分数

## Phase B: API 层 ✅

**完成日期**: 2025-12-19

### B1: 文档搜索 API ✅

**文件**: `src/app/api/document-search/route.ts`

端点: `POST /api/document-search`

请求:
```typescript
{
  query: string;
  options?: { limit?: number }
}
```

响应:
```typescript
{
  selectedDocuments: SearchResultDocument[];
  intent: { query, keywords, year? };
  meta: { totalFound, autoSelectedCount }
}
```

### B2: 查询意图分析 ✅

**文件**: `src/lib/query-intent.ts`

实现要点:
- 使用 LLM 分析用户问题意图
- 提取关键词、年份、文档类型等过滤条件
- 输出: `IntentAnalysisResult { filters, keywords, originalQuery }`

### B3: 文档选择器 ✅

**文件**: `src/lib/document-selector.ts`

实现要点:
- 编排意图分析 + 混合搜索 + Top-N 选择
- 支持 forceYear 强制过滤
- 输出: `DocumentSelectionResult`

### B4: API 验证 Schema ✅

**文件**: `src/lib/validation/api-schemas.ts`

新增:
- `DocumentSearchRequestSchema` - 文档搜索请求验证
- 集成到 document-search API 路由
