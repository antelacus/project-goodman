## 1. 设计目标

### 1.1 核心目标

将系统安全等级从 **MVP 演示级别** 提升到 **生产就绪级别**，实现全面的服务端安全防护。

**关键理念**:
- 安全是**分层防御**，不依赖单一措施
- 使用 Redis 作为分布式状态存储（速率限制、会话、暴力破解计数）
- 最小化对现有业务逻辑的侵入
- 为未来用户管理系统 (V3.7) 预留扩展点

### 1.2 非目标

- ❌ 不实现完整用户管理系统（延迟到 V3.7）
- ❌ 不添加 WAF 或 DDoS 防护（依赖 VPS 提供商）
- ❌ 不修改业务逻辑或 API 行为
- ❌ 不添加 OAuth/SSO 集成

## 2. 架构设计

### 2.1 当前架构问题

```
当前请求流程（无安全防护层）:
┌─────────────────────────────────────────────────────────┐
│  Client Request                                         │
│       ↓                                                 │
│  Next.js API Route (直接处理)                            │
│       ↓                                                 │
│  Manual validation (零散，无长度限制)                     │
│       ↓                                                 │
│  Business logic                                         │
│       ↓                                                 │
│  Response (包含详细错误信息)                              │
└─────────────────────────────────────────────────────────┘

安全缺口:
✗ 无服务端速率限制 → API 滥用、OpenAI 成本失控
✗ 明文密码存储 → 数据库泄露即密码暴露
✗ 详细错误暴露 → 信息泄露辅助攻击
✗ 无输入长度验证 → 资源耗尽攻击
✗ 内存会话存储 → 重启丢失、无法水平扩展
✗ 无暴力破解防护 → 密码可被穷举
✗ 无安全头 → XSS、点击劫持攻击
```

### 2.2 目标架构

```
目标请求流程（分层安全防护）:
┌─────────────────────────────────────────────────────────┐
│  Client Request                                         │
│       ↓                                                 │
│  [nginx] ─── 访问日志、基础过滤                          │
│       ↓                                                 │
│  [Next.js Middleware] ─┬─ 安全头注入                     │
│                        ├─ IP 提取                        │
│                        ├─ 请求 ID 生成                   │
│                        └─ 速率限制检查 ←──── [Redis]     │
│       ↓                              ↑                   │
│  [API Route] ─────────┬─ 输入验证 (Zod + 长度限制)       │
│                       ├─ 会话验证 ←───────── [Redis]     │
│                       ├─ 暴力破解检查 ←───── [Redis]     │
│                       └─ 审计日志写入                    │
│       ↓                                                 │
│  Business logic                                         │
│       ↓                                                 │
│  [Error Handler] ─── 错误脱敏（基于环境）                 │
│       ↓                                                 │
│  Response (生产环境无敏感信息)                            │
└─────────────────────────────────────────────────────────┘
```

### 2.3 Redis 数据结构

```
Redis Key 结构设计:
├── rate:{endpoint}:{ip}          # 速率限制计数
│   └── TTL: 60 秒 (滑动窗口)
│   └── Value: { count, windowStart }
│
├── session:{token}               # 会话数据

│   └── TTL: 15 分钟
```

```typescript
  data: unknown
```

### 3.5 REQ-004: 密码哈希

**文件**: `src/lib/security/password.ts`

**设计**: bcrypt 哈希 + 自动迁移

```typescript
import bcrypt from 'bcryptjs';

const BCRYPT_COST = 12;  // 安全与性能平衡

// 哈希密码
async function hashPassword(plaintext: string): Promise<string> {
  return bcrypt.hash(plaintext, BCRYPT_COST);
}

// 验证密码（支持明文迁移）
async function verifyPassword(
  plaintext: string,
  stored: string
): Promise<{ valid: boolean; needsRehash: boolean }> {
  // 检查是否为 bcrypt 格式 ($2a$ 或 $2b$ 开头)
  if (stored.startsWith('$2')) {
    const valid = await bcrypt.compare(plaintext, stored);
    return { valid, needsRehash: false };
  }

  // 明文比较（迁移兼容）
  const valid = plaintext === stored;
  return { valid, needsRehash: valid };  // 验证成功则需要升级
}
```

**迁移策略**:
1. 首次部署后，通过管理脚本对现有密码进行哈希
2. 或在首次登录成功时自动升级（更新环境变量）

### 3.6 REQ-005: 会话管理

**文件**: `src/lib/security/session.ts`

**设计**: Redis 存储 + HTTP-only Cookie

```typescript
import { v4 as uuidv4 } from 'uuid';
import { redis } from '../redis';

interface SessionData {
  token: string;
  createdAt: string;       // ISO 8601
  expiresAt: string;       // ISO 8601
  ip: string;
  userAgent: string;
  // V3.7 扩展字段
  userId?: string;
  role?: 'admin' | 'user' | 'guest';
}

const SESSION_TTL = 24 * 60 * 60;  // 24 小时（秒）
const SESSION_KEY_PREFIX = 'session:';

// 创建会话
async function createSession(ip: string, userAgent: string): Promise<SessionData> {
  const token = uuidv4();
  const now = new Date();
  const expiresAt = new Date(now.getTime() + SESSION_TTL * 1000);

  const session: SessionData = {
    token,
    createdAt: now.toISOString(),
    expiresAt: expiresAt.toISOString(),
    ip,
    userAgent,
    role: 'admin',  // 当前仅单一管理员
  };

  await redis.set(
    `${SESSION_KEY_PREFIX}${token}`,
    JSON.stringify(session),
    SESSION_TTL
  );

  return session;
}

// 验证会话
async function verifySession(token: string): Promise<SessionData | null> {
  const data = await redis.get(`${SESSION_KEY_PREFIX}${token}`);
  if (!data) return null;

  const session: SessionData = JSON.parse(data);

  // 检查过期
  if (new Date(session.expiresAt) < new Date()) {
    await redis.del(`${SESSION_KEY_PREFIX}${token}`);
    return null;
  }

  return session;
}

// 销毁会话
async function destroySession(token: string): Promise<void> {
  await redis.del(`${SESSION_KEY_PREFIX}${token}`);
}

// 续期会话（活跃用户）
async function renewSession(token: string): Promise<boolean> {
  const session = await verifySession(token);
  if (!session) return false;

  session.expiresAt = new Date(Date.now() + SESSION_TTL * 1000).toISOString();
  await redis.set(
    `${SESSION_KEY_PREFIX}${token}`,
    JSON.stringify(session),
    SESSION_TTL
  );

  return true;
}
```

### 3.7 REQ-006: 暴力破解防护

**文件**: `src/lib/security/brute-force.ts`

**设计**: 指数退避 + 账户锁定

```typescript
interface BruteForceState {
  count: number;
  lastAttempt: number;  // Unix timestamp
  lockedUntil?: number; // Unix timestamp
}

const LOCKOUT_THRESHOLDS = {
  DELAY_AFTER: 3,        // 3 次失败后开始延迟
  LOCK_AFTER: 6,         // 6 次失败后锁定
  DELAY_SECONDS: 2,      // 延迟秒数
  LOCK_DURATION: 15 * 60, // 锁定 15 分钟
};

const BRUTEFORCE_KEY_PREFIX = 'bruteforce:';
const BRUTEFORCE_TTL = 15 * 60;  // 15 分钟

// 检查是否可以尝试
async function checkBruteForce(
  ip: string,
  identifier: string = 'admin'
): Promise<{ allowed: boolean; waitSeconds?: number }> {
  const key = `${BRUTEFORCE_KEY_PREFIX}${ip}:${identifier}`;
  const data = await redis.get(key);

  if (!data) return { allowed: true };

  const state: BruteForceState = JSON.parse(data);

  // 检查锁定
  if (state.lockedUntil && Date.now() < state.lockedUntil) {
    const waitSeconds = Math.ceil((state.lockedUntil - Date.now()) / 1000);
    return { allowed: false, waitSeconds };
  }

  // 检查是否需要延迟
  if (state.count >= LOCKOUT_THRESHOLDS.DELAY_AFTER) {
    const waitSeconds = LOCKOUT_THRESHOLDS.DELAY_SECONDS;
    return { allowed: true, waitSeconds };  // 允许但需等待
  }

  return { allowed: true };
}

// 记录失败尝试
async function recordFailedAttempt(
  ip: string,
  identifier: string = 'admin'
): Promise<{ locked: boolean; lockDuration?: number }> {
  const key = `${BRUTEFORCE_KEY_PREFIX}${ip}:${identifier}`;
  const data = await redis.get(key);

  let state: BruteForceState = data
    ? JSON.parse(data)
    : { count: 0, lastAttempt: 0 };

  state.count += 1;
  state.lastAttempt = Date.now();

  // 达到锁定阈值
  if (state.count >= LOCKOUT_THRESHOLDS.LOCK_AFTER) {
    state.lockedUntil = Date.now() + LOCKOUT_THRESHOLDS.LOCK_DURATION * 1000;
    await redis.set(key, JSON.stringify(state), LOCKOUT_THRESHOLDS.LOCK_DURATION);
    return { locked: true, lockDuration: LOCKOUT_THRESHOLDS.LOCK_DURATION };
  }

  await redis.set(key, JSON.stringify(state), BRUTEFORCE_TTL);
  return { locked: false };
}

// 登录成功后重置
async function resetBruteForce(ip: string, identifier: string = 'admin'): Promise<void> {
  const key = `${BRUTEFORCE_KEY_PREFIX}${ip}:${identifier}`;
  await redis.del(key);
}
```

### 3.8 REQ-007: 文件路径验证

**文件**: `src/lib/security/path-validator.ts`

**设计**: 路径规范化 + 沙箱检查

```typescript
import path from 'path';

// 允许的基础目录
const ALLOWED_BASES = [
  '/tmp/goodman-uploads',  // 临时上传目录
];

interface PathValidationResult {
  valid: boolean;
  normalizedPath?: string;
  error?: string;
}

function validateFilePath(
  inputPath: string,
  allowedBases: string[] = ALLOWED_BASES
): PathValidationResult {
  // 拒绝空字节
  if (inputPath.includes('\0')) {
    return { valid: false, error: '路径包含非法字符' };
  }

  // 规范化路径
  const normalized = path.resolve(inputPath);

  // 检查是否在允许的目录内
  const isAllowed = allowedBases.some(base =>
    normalized.startsWith(path.resolve(base) + path.sep) ||
    normalized === path.resolve(base)
  );

  if (!isAllowed) {
    return { valid: false, error: '访问被拒绝' };
  }

  return { valid: true, normalizedPath: normalized };
}
```

### 3.10 REQ-009: 文件内容验证

**文件**: `src/lib/security/file-validator.ts`

**设计**: 魔数检测

```typescript
// 文件签名（魔数）
const FILE_SIGNATURES: Record<string, { magic: number[]; offset?: number }> = {
  'application/pdf': { magic: [0x25, 0x50, 0x44, 0x46] },  // %PDF
  'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet': {
    magic: [0x50, 0x4B, 0x03, 0x04],  // PK (ZIP)
  },
  'image/png': { magic: [0x89, 0x50, 0x4E, 0x47] },
  'image/jpeg': { magic: [0xFF, 0xD8, 0xFF] },
};

interface FileValidationResult {
  valid: boolean;
  detectedType?: string;
  error?: string;
}

async function validateFileContent(
  buffer: Buffer,
  declaredType: string
): Promise<FileValidationResult> {
  const signature = FILE_SIGNATURES[declaredType];

  // 文本文件不检查魔数
  if (declaredType === 'text/markdown' || declaredType === 'text/plain') {
    // 检查是否为有效 UTF-8
    try {
      buffer.toString('utf-8');
      return { valid: true, detectedType: declaredType };
    } catch {
      return { valid: false, error: '文件编码无效' };
    }
  }

  if (!signature) {
    return { valid: false, error: '不支持的文件类型' };
  }

  // 检查魔数
  const offset = signature.offset || 0;
  const matches = signature.magic.every(
    (byte, i) => buffer[offset + i] === byte
  );

  if (!matches) {
    return { valid: false, error: '文件内容与声明类型不符' };
  }

  return { valid: true, detectedType: declaredType };
}
```

```typescript
import fs from 'fs';
import path from 'path';

interface AuditLogEntry {
  timestamp: string;       // ISO 8601

const LOG_DIR = process.env.AUDIT_LOG_DIR || '/var/log/goodman';
const MAX_LOG_SIZE = 10 * 1024 * 1024;  // 10MB

class AuditLogger {
  private logFile: string;

  constructor() {

  }

  async log(entry: Omit<AuditLogEntry, 'timestamp'>): Promise<void> {
    const fullEntry: AuditLogEntry = {

    };

    const line = JSON.stringify(fullEntry) + '\n';

    await this.rotateIfNeeded();

    // 追加写入
    fs.appendFileSync(this.logFile, line, 'utf-8');
  }

  private async rotateIfNeeded(): Promise<void> {
    try {
      const stats = fs.statSync(this.logFile);
      if (stats.size >= MAX_LOG_SIZE) {
        const rotatedName = `audit.${new Date().toISOString().slice(0, 10)}.log`;
        fs.renameSync(this.logFile, path.join(LOG_DIR, rotatedName));
      }
    } catch {
      // 文件不存在，无需轮转
    }
  }
}

export const auditLogger = new AuditLogger();

// 快捷方法
export function logAuthEvent(
  action: string,
```

## 4. 中间件设计

**文件**: `src/middleware.ts` (新建)

**设计**: 集中式安全检查入口

```typescript
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { checkRateLimit } from './lib/security/rate-limiter';
import { generateRequestId } from './lib/security/error-handler';

export async function middleware(request: NextRequest) {
  const requestId = generateRequestId();
  const ip = getClientIP(request);
  const pathname = request.nextUrl.pathname;

  // 跳过静态资源和健康检查
  if (shouldSkipSecurity(pathname)) {
    return NextResponse.next();
  }

  // 速率限制检查
  const rateLimit = await checkRateLimit(ip, pathname);

  if (!rateLimit.allowed) {
    return new NextResponse(
      JSON.stringify({ error: '请求过于频繁，请稍后重试', requestId }),
      {
        status: 429,
        headers: {
          'Content-Type': 'application/json',
          'X-RateLimit-Limit': String(rateLimit.limit),
          'X-RateLimit-Remaining': '0',
          'X-RateLimit-Reset': String(rateLimit.resetAt),
          'X-Request-ID': requestId,
        },
      }
    );
  }

  // 添加请求 ID 到响应头
  const response = NextResponse.next();
  response.headers.set('X-Request-ID', requestId);
  response.headers.set('X-RateLimit-Limit', String(rateLimit.limit));
  response.headers.set('X-RateLimit-Remaining', String(rateLimit.remaining));
  response.headers.set('X-RateLimit-Reset', String(rateLimit.resetAt));

  return response;
}

function getClientIP(request: NextRequest): string {
  // nginx 代理设置的真实 IP
  const forwarded = request.headers.get('x-forwarded-for');
  if (forwarded) {
    return forwarded.split(',')[0].trim();
  }
  return request.headers.get('x-real-ip') || '127.0.0.1';
}

function shouldSkipSecurity(pathname: string): boolean {
  const skipPaths = [
    '/_next',
    '/favicon.ico',
    '/api/health',
  ];
  return skipPaths.some(p => pathname.startsWith(p));
}

export const config = {
  matcher: [
    '/((?!_next/static|_next/image|favicon.ico).*)',
  ],
};
```
