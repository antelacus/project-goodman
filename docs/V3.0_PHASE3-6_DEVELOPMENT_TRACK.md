## Issues Encountered & Resolutions

### Issue 1: Canvas Native Module Build Failure (Alpine)
**Problem**: Canvas package failed to compile on node:20-alpine due to missing build dependencies.

**Resolution**:
1. Added Python, make, g++ and cairo libraries to Alpine
2. Still failed with C++ compilation errors in FontParser.cc
3. Switched from `node:20-alpine` to `node:20-bookworm-slim` (Debian-based)
4. Added all canvas dependencies (libcairo2-dev, libpango1.0-dev, etc.)

### Issue 2: OPENAI_API_KEY Missing at Build Time
**Problem**: Next.js build failed because API routes initialize OpenAI client at build time.

**Resolution**: Added `OPENAI_API_KEY` and `SUPABASE_SERVICE_ROLE_KEY` as build ARGs in both Dockerfile and docker-compose.yml.

### Issue 3: Heredoc/YAML Issues in zsh
**Problem**: Copy-pasting YAML via heredoc in zsh corrupted indentation.

**Resolution**: Created docker-compose.yml locally and transferred via `scp`.

### Issue 4: SSH Config Not Created
**Problem**: Heredoc for SSH config didn't create file properly in zsh.

**Resolution**: Used `echo` command instead of heredoc.
