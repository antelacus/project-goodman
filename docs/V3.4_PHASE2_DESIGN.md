## 1. 概述

### 1.1 设计目标

将现有三个工作流（Landing Chat、Financial Analysis、Guidance Chat）从手动 if/else 编排迁移到 LangGraph StateGraph 框架，实现：

- 声明式图定义替代命令式控制流
- 条件边实现动态路由
- Reducer 策略确保状态安全合并
- Result Pattern 错误处理保持用户友好的错误信息

### 1.2 关键设计决策（来自 Phase 1）

| 决策 | 选择 | 原因 |
|------|------|------|
| Reducer 策略 | 对象合并 `{ ...prev, ...next }` | 防止复杂字段数据丢失 |
| 错误处理 | Result Pattern（状态内错误字段） | 保留错误上下文供 `generateResponse` 生成用户友好解释 |
| 可审计性 | 步骤日志 + 图导出脚本 | 财务审计需要过程追踪 |
| 迁移顺序 | Landing Chat → Financial Analysis → Guidance Chat | 从简单到复杂，降低风险 |

### 1.3 LangGraph 核心概念

```
┌─────────────────────────────────────────────────────────────────┐
│  LangGraph StateGraph 核心概念                                   │
├─────────────────────────────────────────────────────────────────┤
│  Annotation.Root     定义状态结构，含 reducer 和 default 配置     │
│  StateGraph          图定义类，用于添加节点和边                    │
│  addNode(name, fn)   添加节点，fn 接收 state 返回 Partial<state>  │
│  addEdge(a, b)       添加普通边（a → b）                          │
│  addConditionalEdges 添加条件边，基于路由函数决定下一节点           │
│  START / END         特殊节点，表示图的入口和出口                   │
│  compile()           编译图，返回可执行的 CompiledGraph            │
└─────────────────────────────────────────────────────────────────┘
```

### 2.1 整体架构

```
┌──────────────────────────────────────────────────────────────────────┐
│                          API Routes                                   │
│  /api/financial-analysis  /api/guidance-chat  /api/landing-chat      │
└───────────────┬───────────────────┬─────────────────┬────────────────┘
                │                   │                 │
                ▼                   ▼                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│                     Compiled StateGraphs                              │
│  financialAnalysisGraph   guidanceChatGraph    landingChatGraph      │
│         │                       │                      │              │
│         │  .invoke(input)       │  .invoke(input)      │  .invoke()   │
│         ▼                       ▼                      ▼              │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐       │
│  │  StateGraph     │  │  StateGraph     │  │  StateGraph     │       │
│  │  with nodes     │  │  with nodes     │  │  with nodes     │       │
│  │  and edges      │  │  and edges      │  │  and edges      │       │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘       │
└──────────────────────────────────────────────────────────────────────┘
                │                   │                 │
                ▼                   ▼                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│                       Node Adapters (nodes.ts)                        │
│  将现有 steps.ts 函数适配为 LangGraph 节点签名                          │
│  StepFunction: (state) => state                                       │
│  NodeFunction: (state) => Partial<state>                              │
└──────────────────────────────────────────────────────────────────────┘
                │                   │                 │
                ▼                   ▼                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│                       Step Functions (steps.ts)                       │
│  现有业务逻辑，保持不变，仅被节点适配器调用                              │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 调用流程

```
API Route
    │
    ▼
graph.invoke({ input: {...} })
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  StateGraph Execution                                        │
│                                                              │
│  START ──► Node1 ──► [条件边] ──► Node2 ──► ... ──► END     │
│                         │                                    │
│                         ▼                                    │
│                  Routing Function                            │
│                  (检查 state 决定下一节点)                    │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
Return final state.output
```

## 3. State Annotation 定义

### 3.1 设计原则

1. **复用现有类型**: 直接引用 `workflow-states.ts` 中定义的类型
2. **Reducer 策略**:
   - 简单字段：`(prev, next) => next ?? prev`（保留最新值，null 保留前者）
   - 复杂对象：`(prev, next) => ({ ...prev, ...next })`（浅合并）
   - 数组字段：`(prev, next) => [...(prev ?? []), ...(next ?? [])]`（追加）
3. **Default 值**: 提供合理的初始值，避免 undefined 错误

### 3.2 Landing Chat State Annotation

```typescript
// src/lib/workflows/landing-chat/state.ts
import { Annotation } from "@langchain/langgraph";
import type { LandingChatState, WorkflowMeta, SerializedWorkflowError } from "@/lib/types/workflow-states";
import type { ChatMessage, IntentAnalysis, SuggestedModule } from "@/lib/types/domain-types";

/**
 * Landing Chat 状态注解
 *
 * 线性流程，无复杂条件边，Reducer 策略相对简单
 */
export const LandingChatAnnotation = Annotation.Root({
  // 输入：保留最新值
  input: Annotation<{
    messages: ChatMessage[];
    currentMessage: string;
  }>({
    reducer: (prev, next) => next ?? prev,
    default: () => ({ messages: [], currentMessage: "" }),
  }),

  // 步骤 1: 生成回复
  reply: Annotation<{
    content: string;
    conversationHistory: ChatMessage[];
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({ content: "", conversationHistory: [] }),
  }),

  // 步骤 2: 路由分析
  routing: Annotation<{
    intentAnalysis: IntentAnalysis;
    suggestedModule?: SuggestedModule;
    confidence: number;
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({
      intentAnalysis: { extractionKeywords: 0, analysisKeywords: 0, guidanceKeywords: 0 },
      confidence: 0,
    }),
  }),

  // 步骤 3: 建议问题
  suggestions: Annotation<{
    questions: string[];
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({ questions: [] }),
  }),

  // 最终输出
  output: Annotation<{
    reply: string;
    suggestedModule?: SuggestedModule;
    suggestedQuestions?: string[];
    confidence: number;
  }>({
    reducer: (prev, next) => next ?? prev,
    default: () => ({ reply: "", confidence: 0 }),
  }),

  // 元数据：errors 需要追加
  meta: Annotation<WorkflowMeta>({
    reducer: (prev, next) => ({
      ...prev,
      ...next,
      errors: [...(prev?.errors ?? []), ...(next?.errors ?? [])],
    }),
    default: () => ({
      startTime: Date.now(),
      currentStep: "init",
      errors: [],
    }),
  }),
});

// 类型导出（用于节点函数签名）
export type LandingChatGraphState = typeof LandingChatAnnotation.State;
```

### 3.3 Financial Analysis State Annotation

```typescript
// src/lib/workflows/financial-analysis/state.ts
import { Annotation } from "@langchain/langgraph";
import type {
  FinancialAnalysisState,
  WorkflowMeta,
  ConfidenceEvaluation,
} from "@/lib/types/workflow-states";
import type {
  SourceDocument,
  CalculationValue,
  DocumentSelectionResult,
  FinancialMetricDataExtended,
} from "@/lib/types/domain-types";

/**
 * Financial Analysis 状态注解
 *
 * 含两个条件边（routeToFunction → queryData, queryData → executeCalculation）
 * dataQuery 和 calculation 是高风险字段，必须使用对象合并 Reducer
 */
export const FinancialAnalysisAnnotation = Annotation.Root({
  // 输入
  input: Annotation<{
    question: string;
    year?: string;
    period?: string;
    documentIds?: string[];
    autoSelect?: { enabled: boolean; maxDocuments?: number };
  }>({
    reducer: (prev, next) => next ?? prev,
    default: () => ({ question: "" }),
  }),

  // 步骤 0: 文档选择
  documentSelection: Annotation<DocumentSelectionResult | undefined>({
    reducer: (prev, next) => next ?? prev,
    default: () => undefined,
  }),

  // 步骤 1: 函数路由
  routing: Annotation<{
    selectedFunction: string | null;
    functionArgs: Record<string, unknown>;
    confidence: number;
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({
      selectedFunction: null,
      functionArgs: {},
      confidence: 0,
    }),
  }),

  // 步骤 2: 数据查询 ⚠️ 高风险字段
  dataQuery: Annotation<{
    requiredMetrics: string[];
    availableMetrics: string[];
    missingMetrics: string[];
    dataMap: Record<string, FinancialMetricDataExtended>;
    sourceDocuments: SourceDocument[];
    error?: {
      code: string;
      message: string;
      details?: Record<string, unknown>;
    };
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({
      requiredMetrics: [],
      availableMetrics: [],
      missingMetrics: [],
      dataMap: {},
      sourceDocuments: [],
    }),
  }),

  // 步骤 3: 计算执行 ⚠️ 高风险字段
  calculation: Annotation<{
    functionName: string;
    functionDisplayName: string;
    formula: string;
    inputs: Record<string, number>;
    result: CalculationValue;
    steps: string[];
    warnings?: string[];
    error?: {
      code: string;
      message: string;
    };
  }>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({
      functionName: "",
      functionDisplayName: "",
      formula: "",
      inputs: {},
      result: { value: 0, formatted: "", unit: "" },
      steps: [],
    }),
  }),

  // 步骤 4: 置信度评估
  confidence: Annotation<ConfidenceEvaluation>({
    reducer: (prev, next) => ({ ...prev, ...next }),
    default: () => ({
      score: 0,
      factors: [],
      threshold: 0.7,
      passed: false,
    }),
  }),

  // 最终输出
  output: Annotation<FinancialAnalysisState["output"]>({
    reducer: (prev, next) => next ?? prev,
    default: () => ({
      type: "no_function",
      answer: "",
      confidence: 0,
      sourceDocuments: [],
    }),
  }),

  // 元数据
  meta: Annotation<WorkflowMeta>({
    reducer: (prev, next) => ({
      ...prev,
      ...next,
      errors: [...(prev?.errors ?? []), ...(next?.errors ?? [])],
    }),
    default: () => ({
      startTime: Date.now(),
      currentStep: "init",
      errors: [],
    }),
  }),
});

export type FinancialAnalysisGraphState = typeof FinancialAnalysisAnnotation.State;
```

## 4. 节点适配器模式

### 4.1 适配器设计原理

**问题**：现有 steps.ts 函数返回完整 state，LangGraph 节点需返回 Partial<state>。

**解决方案**：创建 nodes.ts 适配器层，调用现有步骤函数并提取更新部分。

```
┌─────────────────────────────────────────────────────────────┐
│  steps.ts (现有)                                             │
│  export async function routeToFunction(state): Promise<state>│
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  nodes.ts (新增适配器)                                       │
│  export const routeToFunctionNode = async (state) => {      │
│    const result = await steps.routeToFunction(state as any);│
│    return {                                                  │
│      routing: result.routing,                               │
│      meta: { currentStep: "route_to_function" }             │
│    };                                                        │
│  }                                                           │
└─────────────────────────────────────────────────────────────┘
```

```typescript
import * as steps from "./steps";
import { performDocumentSelection } from "../shared/document-selection";
import type { FinancialAnalysisGraphState } from "./state";
import type { FinancialAnalysisState } from "@/lib/types/workflow-states";

/**
 * 文档选择节点
 */
export const selectDocumentsNode = async (
  state: FinancialAnalysisGraphState
): Promise<Partial<FinancialAnalysisGraphState>> => {
  const result = await performDocumentSelection(state as FinancialAnalysisState);
  return {
    documentSelection: result.documentSelection,
    meta: { ...state.meta, currentStep: "select_documents" },
  };
};

/**
 * 路由到函数节点
 */
export const routeToFunctionNode = async (
  state: FinancialAnalysisGraphState
): Promise<Partial<FinancialAnalysisGraphState>> => {
  const result = await steps.routeToFunction(state as FinancialAnalysisState);
  return {
    routing: result.routing,
    meta: { ...state.meta, currentStep: "route_to_function" },
  };
};

/**
 * 查询数据节点
 */
export const queryDataNode = async (
  state: FinancialAnalysisGraphState
): Promise<Partial<FinancialAnalysisGraphState>> => {
  try {
    const result = await steps.queryData(state as FinancialAnalysisState);
    return {
      dataQuery: result.dataQuery,
      meta: { ...state.meta, currentStep: "query_data" },
    };
  } catch (error) {
    // Result Pattern: 错误存入状态而非抛出
    return {
      dataQuery: {
        ...state.dataQuery,
        error: {
          code: "QUERY_FAILED",
          message: error instanceof Error ? error.message : "Unknown error",
        },
      },
      meta: { ...state.meta, currentStep: "query_data" },
    };
  }
};

 * 执行计算节点
 */
export const executeCalculationNode = async (
  state: FinancialAnalysisGraphState
): Promise<Partial<FinancialAnalysisGraphState>> => {

    const result = await steps.executeCalculation(state as FinancialAnalysisState);
    return {
      calculation: result.calculation,
      meta: { ...state.meta, currentStep: "execute_calculation" },
    };
  } catch (error) {
    return {
      calculation: {
        ...state.calculation,

          code: "CALCULATION_FAILED",

    output: result.output,
    meta: { ...state.meta, currentStep: "generate_response", endTime: Date.now() },
  };
};
```

```typescript
// src/lib/workflows/financial-analysis/graph.ts

/**
 * 条件边 1: routeToFunction 之后
 *
 * 决策逻辑：
 * - 如果 selectedFunction 为 null → generateResponse（无匹配函数）
 * - 否则 → queryData（继续正常流程）
 */
const afterRouteToFunction = (state: FinancialAnalysisGraphState): string => {
  if (!state.routing.selectedFunction) {
    return "generateResponse";
  }
  return "queryData";
};

/**
 * 条件边 2: queryData 之后
 *
 * 决策逻辑：
 * - 如果有错误 → generateResponse（错误处理）
 * - 如果有缺失数据 → generateResponse（数据不足）
 * - 否则 → executeCalculation（继续计算）
 */
const afterQueryData = (state: FinancialAnalysisGraphState): string => {
  // 错误优先
  if (state.dataQuery.error) {
    return "generateResponse";
  }
  // 数据不足
  if (state.dataQuery.missingMetrics.length > 0) {
    return "generateResponse";
  }
  return "executeCalculation";
};
```

```typescript
// src/lib/workflows/shared/graph-utils.ts
import type { WorkflowMeta } from "@/lib/types/workflow-states";

/**
 * 创建步骤日志记录器
 * 在每个节点执行后打印节点名称和关键状态
 */
export function createStepLogger(graphName: string) {
  return (nodeName: string, state: Record<string, unknown>) => {
    const timestamp = new Date().toISOString();
    console.log(`[${graphName}] ${timestamp} | Node: ${nodeName}`);

    // 只打印关键字段，避免输出过大
    const summary: Record<string, unknown> = {};

    if (state.routing) {
      summary.routing = {
        selectedFunction: (state.routing as any).selectedFunction,
        confidence: (state.routing as any).confidence,
      };
    }

    if (state.dataQuery) {
      summary.dataQuery = {
        missingMetrics: (state.dataQuery as any).missingMetrics?.length ?? 0,
        hasError: !!(state.dataQuery as any).error,
      };
    }

    if (state.confidence) {
      summary.confidence = {
        score: (state.confidence as any).score,
        passed: (state.confidence as any).passed,
      };
    }

    if (state.output) {
      summary.output = {
        type: (state.output as any).type,
      };
    }

    console.log(`[${graphName}] State summary:`, JSON.stringify(summary, null, 2));
    console.log("---");
  };
}

/**
 * 为节点函数添加日志包装
 */
export function withLogging<TState extends Record<string, unknown>>(
  graphName: string,
  nodeName: string,
  nodeFunction: (state: TState) => Promise<Partial<TState>>
): (state: TState) => Promise<Partial<TState>> {
  const logger = createStepLogger(graphName);

  return async (state: TState) => {
    console.log(`[${graphName}] Entering node: ${nodeName}`);
    const result = await nodeFunction(state);
    logger(nodeName, { ...state, ...result });
    return result;
  };
}

/**
 * 生成人类可读的错误消息
 */
export function generateHumanReadableError(error: {
  code: string;
  message: string;
  details?: Record<string, unknown>;
}): string {
  const templates: Record<string, (e: typeof error) => string> = {
    INSUFFICIENT_DATA: (e) =>
      `未找到${(e.details?.missingItems as string[])?.join("、") || "必需数据"}，请确认已上传相关文档。`,
    DOCUMENT_NOT_FOUND: (e) =>
      `未找到${e.details?.year || ""}年的${e.details?.docType || "财务报表"}。`,
    QUERY_FAILED: (e) => `数据查询失败：${e.message}。请稍后重试。`,
    CALCULATION_FAILED: (e) => `计算执行失败：${e.message}。`,
    SEARCH_FAILED: (e) => `搜索失败：${e.message}。请稍后重试。`,
  };

  return templates[error.code]?.(error) || error.message;
}
```

```typescript
  );

  for (const { name, graph } of graphs) {
    try {
      // 获取图的可绘制表示
      const drawable = graph.getGraph();

      // 导出 PNG 图片
      const image = await drawable.drawMermaidPng();
      const arrayBuffer = await image.arrayBuffer();

      const pngPath = path.join(outputDir, `${name}-graph.png`);
      fs.writeFileSync(pngPath, buffer);
      console.log(`✅ Exported: ${pngPath}`);
    } catch (error) {
      console.error(`❌ Failed to export ${name}:`, error);
    }
  }

  console.log("\n📊 Graph export complete!");
}
```

## 附录 A: Graph.ts 完整示例（Financial Analysis）

```typescript
// src/lib/workflows/financial-analysis/graph.ts
import { StateGraph, START, END } from "@langchain/langgraph";
import { FinancialAnalysisAnnotation, type FinancialAnalysisGraphState } from "./state";
import * as nodes from "./nodes";
import { withLogging } from "../shared/graph-utils";

const GRAPH_NAME = "FinancialAnalysis";

// 条件边：路由后决策
const afterRouteToFunction = (state: FinancialAnalysisGraphState): string => {
  if (!state.routing.selectedFunction) {
    return "generateResponse";
  }
  return "queryData";
};

// 条件边：查询数据后决策
const afterQueryData = (state: FinancialAnalysisGraphState): string => {
  if (state.dataQuery.error) {
    return "generateResponse";
  }
  if (state.dataQuery.missingMetrics.length > 0) {
    return "generateResponse";
  }
  return "executeCalculation";
};

// 构建图
const workflow = new StateGraph(FinancialAnalysisAnnotation)
  // 添加节点（带日志）
  .addNode("selectDocuments", withLogging(GRAPH_NAME, "selectDocuments", nodes.selectDocumentsNode))
  .addNode("routeToFunction", withLogging(GRAPH_NAME, "routeToFunction", nodes.routeToFunctionNode))
  .addNode("queryData", withLogging(GRAPH_NAME, "queryData", nodes.queryDataNode))
  .addNode("executeCalculation", withLogging(GRAPH_NAME, "executeCalculation", nodes.executeCalculationNode))
  .addNode("evaluateConfidence", withLogging(GRAPH_NAME, "evaluateConfidence", nodes.evaluateConfidenceNode))
  .addNode("generateResponse", withLogging(GRAPH_NAME, "generateResponse", nodes.generateResponseNode))

  // 添加边
  .addEdge(START, "selectDocuments")
  .addEdge("selectDocuments", "routeToFunction")
  .addConditionalEdges("routeToFunction", afterRouteToFunction, {
    queryData: "queryData",
    generateResponse: "generateResponse",
  })
  .addConditionalEdges("queryData", afterQueryData, {
    executeCalculation: "executeCalculation",
    generateResponse: "generateResponse",
  })
  .addEdge("executeCalculation", "evaluateConfidence")
  .addEdge("evaluateConfidence", "generateResponse")
  .addEdge("generateResponse", END);

// 编译并导出
export const financialAnalysisGraph = workflow.compile();

// 便捷运行函数
export async function runFinancialAnalysisWorkflow(
  input: FinancialAnalysisGraphState["input"]
): Promise<FinancialAnalysisGraphState> {
  const result = await financialAnalysisGraph.invoke({ input });
  return result as FinancialAnalysisGraphState;
}
```
