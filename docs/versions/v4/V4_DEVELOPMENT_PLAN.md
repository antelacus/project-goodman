## 1. 版本控制改进

从 V4 开始，采用改进的版本控制实践：

### 1.1 核心原则

| 方面 | V3 做法 | V4 做法 |
|------|---------|---------|
| **版本号** | 规划时分配 (V3.8, V3.9) | 发布时分配 |
| **功能命名** | 版本号 (V3.8) | 描述性名称 (management-reports) |
| **开发顺序** | 可能乱序 (V3.7→V3.10→V3.9) | 按优先级，版本号反映发布顺序 |

### 1.2 文档结构

```
docs/development-documentation/
├── V4_DEVELOPMENT_PLAN.md          # 本文件：总体规划
├── features/                        # 功能文档（按描述性名称）
│   ├── management-reports/
│   │   ├── PHASE1_PRD.md
│   │   ├── PHASE2_DESIGN.md
│   │   └── PHASE3-6_TRACK.md
│   └── report-generation/
│       └── ...
└── V4.x.x_RELEASE_NOTES.md         # 发布时创建
```

### 1.3 发布流程

1. 功能开发完成 → 合并到 main
2. 决定版本号 (4.0.0, 4.1.0, etc.)
3. 创建 git tag
4. 更新 CHANGELOG.md

## 2. 功能规划

### 2.1 从 V3 移入的功能

#### 管理用财报体系 (原 V3.8)

| 属性 | 详情 |
|------|------|
| **目录** | `features/management-reports/` |
| **描述** | 将传统财务报表重构为管理用财报，支持更深入的财务分析 |
| **依赖** | V3.3 智能文档系统, V3.5 财务 Agent |
| **状态** | 待开始 |

**核心能力**:
- 资产负债表重构（净经营资产、净负债）
- 利润表重构（税前/税后经营利润）
- 现金流量表重构（营业现金流、实体现金流）
- 管理用财务比率（净经营资产净利率、管理用 ROE）

**实施阶段**:
1. 阶段 1：资产/负债经营/金融分类逻辑
2. 阶段 2：利润表重构
3. 阶段 3：现金流量表重构（需智能文档系统提取折旧摊销）
4. 阶段 4：管理用比率和管理用 ROE
