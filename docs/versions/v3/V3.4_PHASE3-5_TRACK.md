## 总结

### 关键成果

1. **去除了意大利面条式代码**: 用声明式的图取代了复杂的 `index.ts` 逻辑控制。
2. **增强可观测性**: 现在的 `graph-utils` 提供了每一步的详细状态日志，包括 LLM 的推理过程。
3. **架构统一**: 3 个主要工作流现在共享相同的架构模式 (State/Nodes/Graph)。

### 发现的局限性 (V3.5 动机)

1. **无记忆**: 无法跨轮次记忆 (e.g. "与去年相比")。
2. **单步执行**: 每次 Request 只能跑一次主逻辑，无法自动循环解决复杂问题。

### 下一步

- **V3.5**: Financial Agent 逻辑升级 (引入记忆和循环)。
