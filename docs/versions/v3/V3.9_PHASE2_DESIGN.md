## 1. 设计概述

### 1.1 设计原则

1. **最小侵入**: 尽量保持现有架构，只修复问题点
2. **向后兼容**: 修复不应破坏现有功能
3. **增量部署**: 按批次实施，每批验证后再继续
4. **可回滚**: 每个变更都应可独立回滚

### 1.2 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| CSRF 实现 | Double Submit Cookie | 无需服务端状态，与现有架构一致 |
| 常量时间比较 | `crypto.timingSafeEqual` | Node.js 原生支持，无需额外依赖 |
| Service Role 隔离 | 注释 + ESLint 规则 | 编译时检查，防止意外导入 |
| 类型生成 | Supabase CLI | 官方工具，保证一致性 |

### 3.4 REQ-005: 消息转换修复

**文件**: `src/lib/workflows/core/nodes/agent-loop.ts`

**当前问题**:
```typescript
// 丢失 tool_call_id
return { role, content: msg.content } as any;
```

**修复设计**:
```typescript
import { BaseMessage, HumanMessage, AIMessage, ToolMessage } from '@langchain/core/messages';

function convertToOpenAIMessages(messages: BaseMessage[]): OpenAIMessage[] {
    return messages.map(msg => {
        if (msg instanceof HumanMessage) {
            return { role: 'user', content: msg.content as string };
        }
        if (msg instanceof AIMessage) {
            const aiMsg: OpenAIMessage = { role: 'assistant', content: msg.content as string };
            if (msg.tool_calls?.length) {
                aiMsg.tool_calls = msg.tool_calls.map(tc => ({
                    id: tc.id,
                    type: 'function',
                    function: { name: tc.name, arguments: JSON.stringify(tc.args) }
                }));
            }
            return aiMsg;
        }
        if (msg instanceof ToolMessage) {
            return {
                role: 'tool',
                tool_call_id: msg.tool_call_id,
                content: msg.content as string
            };
        }
        throw new Error(`Unknown message type: ${msg.constructor.name}`);
    });
}
```

## 4. P1 高优先级修复设计

### 4.1 REQ-007: CSRF 保护

**新增文件**: `src/lib/security/csrf.ts`

**实现方式**: Double Submit Cookie

```typescript
import { cookies } from 'next/headers';
import { randomBytes } from 'crypto';

const CSRF_COOKIE_NAME = 'csrf_token';
const CSRF_HEADER_NAME = 'x-csrf-token';

export async function generateCsrfToken(): Promise<string> {
    const token = randomBytes(32).toString('hex');
    const cookieStore = await cookies();
    cookieStore.set(CSRF_COOKIE_NAME, token, {
        httpOnly: true,
        secure: process.env.NODE_ENV === 'production',
        sameSite: 'strict',
        path: '/'
    });
    return token;
}

export async function validateCsrfToken(request: Request): Promise<boolean> {
    const cookieStore = await cookies();
    const cookieToken = cookieStore.get(CSRF_COOKIE_NAME)?.value;
    const headerToken = request.headers.get(CSRF_HEADER_NAME);

    if (!cookieToken || !headerToken) return false;
    return cookieToken === headerToken;
}
```

**API 路由集成**:
```typescript
// 在需要保护的 API 路由中
import { validateCsrfToken } from '@/lib/security/csrf';

export async function POST(request: Request) {
    if (!await validateCsrfToken(request)) {
        return NextResponse.json({ error: 'Invalid CSRF token' }, { status: 403 });
    }
    // ... 处理请求
}
```

**前端集成**:
```typescript
// 获取 CSRF token
const csrfToken = await fetch('/api/auth/csrf').then(r => r.json()).then(d => d.token);

// 在请求中包含
fetch('/api/documents', {
    method: 'DELETE',
    headers: { 'x-csrf-token': csrfToken }
});
```

### 4.3 REQ-009: 错误处理统一

```typescript
import { NextResponse } from 'next/server';

interface ErrorResponseOptions {
    status: number;
    message: string;
    requestId?: string;
    details?: unknown;  // 仅开发环境
}

export function createErrorResponse(options: ErrorResponseOptions): NextResponse {
    const { status, message, requestId } = options;

    const body: Record<string, unknown> = {
        success: false,
        error: message,
    };

    if (requestId) {
        body.requestId = requestId;
    }

    // 仅开发环境暴露详情
    if (process.env.NODE_ENV === 'development' && options.details) {
        body.details = options.details;
    }

    return NextResponse.json(body, { status });
}
```

**统一应用到所有 API 路由**

### 5.4 REQ-016: 常量时间密码比较

**文件**: `src/lib/security/password.ts`

**当前**:
```typescript

```

**修复**:
```typescript
import { timingSafeEqual } from 'crypto';

function constantTimeCompare(a: string, b: string): boolean {
    if (a.length !== b.length) {
        // 长度不同时，仍需消耗固定时间
        const dummy = Buffer.alloc(32);
        timingSafeEqual(dummy, dummy);
        return false;
    }
    return timingSafeEqual(Buffer.from(a), Buffer.from(b));
}
```
