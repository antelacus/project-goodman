## 1. 设计概述

### 1.1 设计目标

将现有的"用户手动选择文档"模式升级为"AI 自动发现 + 用户可覆盖"模式，同时增强财务报告的章节感知能力以提升检索精度。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **渐进增强** | 在现有架构上增量构建，不大规模重构 |
| **优雅降级** | 章节识别失败时回退到基础搜索 |
| **透明可控** | 用户始终了解并可覆盖 AI 决策 |
| **模块化** | 新功能作为独立模块，便于测试和维护 |

### 1.3 设计约束

- 基于 V3.1 工作流架构构建
- 复用现有 `document_chunks` 表结构
- 保持 API 向后兼容
- 不引入新的数据库表（仅扩展字段）

#### 3.1.1 `document_chunks` 表扩展

```sql
-- 新增字段
ALTER TABLE document_chunks ADD COLUMN IF NOT EXISTS section_title TEXT;
ALTER TABLE document_chunks ADD COLUMN IF NOT EXISTS section_level INTEGER DEFAULT 0;
ALTER TABLE document_chunks ADD COLUMN IF NOT EXISTS section_path TEXT[];

-- 字段说明:
-- section_title: 章节标题 (如 "三、合并财务报表项目注释")
-- section_level: 章节层级 (0=无章节, 1=一级标题, 2=二级标题...)
-- section_path: 章节路径数组 (如 ARRAY['三、合并财务报表项目注释', '（一）货币资金'])
```

**关于现有 `hierarchy JSONB` 字段的处理**：

现有表中已有 `hierarchy JSONB` 字段（20250113 迁移添加），但目前未被使用。我们选择：

| 字段 | 决策 | 原因 |
|------|------|------|
| `section_path TEXT[]` | **使用** | 数组类型更适合 GIN 索引和包含查询 (`@>`) |
| `hierarchy JSONB` | **废弃** | JSONB 查询复杂度高，且当前无数据使用 |

```sql
-- 废弃说明（不删除，保持向后兼容）
COMMENT ON COLUMN document_chunks.hierarchy IS
  'DEPRECATED: 使用 section_path TEXT[] 替代。保留字段以兼容旧数据。';
```

**为什么选择 `TEXT[]` 而非 `JSONB`**：

1. **查询效率**：`section_path @> ARRAY['固定资产']` 比 JSONB 路径查询更快
2. **GIN 索引**：数组的 GIN 索引对包含查询优化更好
3. **简洁性**：路径本质是有序列表，数组语义更匹配

### 3.2 新增 RPC 函数

#### 3.2.1 `search_documents_hybrid` - 真正的混合搜索

采用**多路召回 + RRF 融合**策略，避免单路召回的漏检问题：

```sql
CREATE OR REPLACE FUNCTION search_documents_hybrid(
  query_embedding vector(1536),
  query_text text,                    -- 原始查询文本，用于全文搜索
  match_count int DEFAULT 10,
  section_filter text DEFAULT NULL,
  year_filter int DEFAULT NULL,
  doc_type_filter text DEFAULT NULL,
  vector_weight float DEFAULT 0.5,    -- 向量搜索权重
  keyword_weight float DEFAULT 0.5    -- 关键词搜索权重
)
RETURNS TABLE (
  chunk_id uuid,
  document_id uuid,
  document_name text,
  doc_type text,
  content text,
  section_title text,
  section_path text[],
  vector_rank int,
  keyword_rank int,
  rrf_score float,
  year int,
  period text
)
LANGUAGE plpgsql
AS $$
DECLARE
  k CONSTANT int := 60;  -- RRF 常数，平衡头部和尾部排名
  recall_count CONSTANT int := 20;  -- 每路召回数量
BEGIN
  RETURN QUERY
  WITH
  -- 路径 A: 向量相似度召回 (Top-20)
  vector_recall AS (
    SELECT
      dc.id AS chunk_id,
      dc.document_id,
      d.name AS document_name,
      d.doc_type,
      dc.content,
      dc.section_title,
      dc.section_path,
      d.year,
      d.period,
      ROW_NUMBER() OVER (ORDER BY dc.embedding <=> query_embedding) AS v_rank
    FROM document_chunks dc
    JOIN documents d ON dc.document_id = d.id
    WHERE d.doc_category = 'knowledge'
      AND d.status = 'ready'
      AND (year_filter IS NULL OR d.year = year_filter)
      AND (doc_type_filter IS NULL OR d.doc_type = doc_type_filter)
      AND (section_filter IS NULL OR dc.section_title ILIKE '%' || section_filter || '%')
    ORDER BY dc.embedding <=> query_embedding
    LIMIT recall_count
  ),
  -- 路径 B: 全文搜索召回 (Top-20)
  -- 使用 PostgreSQL 全文搜索，支持中文需配置 simple 或 zhparser
  keyword_recall AS (
    SELECT
      dc.id AS chunk_id,
      dc.document_id,
      d.name AS document_name,
      d.doc_type,
      dc.content,
      dc.section_title,
      dc.section_path,
      d.year,
      d.period,
      ROW_NUMBER() OVER (
        ORDER BY ts_rank_cd(
          to_tsvector('simple', dc.content),
          plainto_tsquery('simple', query_text)
        ) DESC
      ) AS k_rank
    FROM document_chunks dc
    JOIN documents d ON dc.document_id = d.id
    WHERE d.doc_category = 'knowledge'
      AND d.status = 'ready'
      AND (year_filter IS NULL OR d.year = year_filter)
      AND (doc_type_filter IS NULL OR d.doc_type = doc_type_filter)
      AND (section_filter IS NULL OR dc.section_title ILIKE '%' || section_filter || '%')
      AND to_tsvector('simple', dc.content) @@ plainto_tsquery('simple', query_text)
    ORDER BY ts_rank_cd(
      to_tsvector('simple', dc.content),
      plainto_tsquery('simple', query_text)
    ) DESC
    LIMIT recall_count
  ),
  -- 融合: 取并集 + RRF (Reciprocal Rank Fusion)
  combined AS (
    SELECT
      COALESCE(v.chunk_id, k.chunk_id) AS chunk_id,
      COALESCE(v.document_id, k.document_id) AS document_id,
      COALESCE(v.document_name, k.document_name) AS document_name,
      COALESCE(v.doc_type, k.doc_type) AS doc_type,
      COALESCE(v.content, k.content) AS content,
      COALESCE(v.section_title, k.section_title) AS section_title,
      COALESCE(v.section_path, k.section_path) AS section_path,
      COALESCE(v.year, k.year) AS year,
      COALESCE(v.period, k.period) AS period,
      COALESCE(v.v_rank, recall_count + 1) AS vector_rank,
      COALESCE(k.k_rank, recall_count + 1) AS keyword_rank,
      -- RRF 公式: score = w1/(k+rank1) + w2/(k+rank2)
      (vector_weight / (k + COALESCE(v.v_rank, recall_count + 1))) +
      (keyword_weight / (k + COALESCE(k.k_rank, recall_count + 1))) AS rrf_score
    FROM vector_recall v
    FULL OUTER JOIN keyword_recall k ON v.chunk_id = k.chunk_id
  )
  SELECT
    c.chunk_id,
    c.document_id,
    c.document_name,
    c.doc_type,
    c.content,
    c.section_title,
    c.section_path,
    c.vector_rank::int,
    c.keyword_rank::int,
    c.rrf_score,
    c.year,
    c.period
  FROM combined c
  ORDER BY c.rrf_score DESC
  LIMIT match_count;
END;
$$;
```

**RRF (Reciprocal Rank Fusion) 说明**：

- 公式：`score = w1/(k+rank1) + w2/(k+rank2)`
- `k=60` 是常用常数，平衡头部排名差异
- 优势：不依赖分数归一化，适合融合不同量纲的排名

#### 3.2.2 `get_document_sections` - 获取文档章节列表

```sql
CREATE OR REPLACE FUNCTION get_document_sections(
  p_document_id uuid
)
RETURNS TABLE (
  section_title text,
  section_level int,
  chunk_count int
)
LANGUAGE sql
AS $$
  SELECT
    section_title,
    section_level,
    COUNT(*)::int AS chunk_count
  FROM document_chunks
  WHERE document_id = p_document_id
    AND section_title IS NOT NULL
  GROUP BY section_title, section_level
  ORDER BY section_level, section_title;
$$;
```

```typescript
// src/app/api/document-search/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { z } from 'zod';
import { searchDocuments } from '@/lib/document-search';

const requestSchema = z.object({
  query: z.string().min(1).max(500),
  filters: z.object({
    year: z.number().optional(),
    docTypes: z.array(z.string()).optional(),
    sections: z.array(z.string()).optional(),
  }).optional(),
  options: z.object({
    limit: z.number().min(1).max(50).default(10),
    includeContent: z.boolean().default(true),
    threshold: z.number().min(0).max(1).default(0.5),
  }).optional(),
});

export async function POST(request: NextRequest) {
  const body = await request.json();
  const parsed = requestSchema.safeParse(body);

  if (!parsed.success) {
    return NextResponse.json({
      success: false,
      error: parsed.error.message
    }, { status: 400 });
  }

  const results = await searchDocuments(parsed.data);
  return NextResponse.json({ success: true, results });
}
```

### 5.1 章节解析策略

采用三层降级策略，确保任何文档都能被处理：

### 5.2 章节解析器实现

```typescript
// src/lib/section-parser.ts

export interface Section {
  title: string;
  level: number;           // 1, 2, 3...
  startIndex: number;      // 在原文中的起始位置
  endIndex?: number;       // 在原文中的结束位置
  parent?: string;         // 父章节标题
}

export interface ParseResult {
  sections: Section[];
  quality: 'good' | 'moderate' | 'basic';
  hasToc: boolean;
  method: 'toc' | 'heading' | 'basic';
}

// 标题模式定义
const HEADING_PATTERNS = {
  level1: [
    /^[一二三四五六七八九十]+、/,           // 一、二、三、
    /^第[一二三四五六七八九十]+[章节部分]/,  // 第一章、第二节
  ],
  level2: [
    /^（[一二三四五六七八九十]+）/,          // （一）（二）
    /^\([一二三四五六七八九十]+\)/,          // (一)(二)
    /^[1-9]\./,                              // 1. 2. 3.
  ],
  level3: [
    /^[1-9]\.[1-9]/,                         // 1.1 1.2
    /^（[1-9]）/,                            // （1）（2）
    /^\([1-9]\)/,                            // (1)(2)
  ],
};

export async function parseDocumentSections(
  content: string,
  docType: string
): Promise<ParseResult> {
  // 1. 尝试目录检测
  const tocResult = detectTableOfContents(content);
  if (tocResult.found) {
    return {
      sections: tocResult.sections,
      quality: tocResult.sections.length >= 10 ? 'good' : 'moderate',
      hasToc: true,
      method: 'toc',
    };
  }

  // 2. 尝试标题模式识别
  const headingResult = detectHeadingPatterns(content);
  if (headingResult.sections.length >= 5) {
    return {
      sections: headingResult.sections,
      quality: headingResult.sections.length >= 10 ? 'good' : 'moderate',
      hasToc: false,
      method: 'heading',
    };
  }

  // 3. 回退到基础分块
  return {
    sections: [],
    quality: 'basic',
    hasToc: false,
    method: 'basic',
  };
}

function detectTableOfContents(content: string): {
  found: boolean;
  sections: Section[]
} {
  // 查找目录标记
  const tocMarkers = ['目录', '目 录', 'CONTENTS', 'Table of Contents'];
  const tocIndex = tocMarkers.reduce((idx, marker) => {
    const found = content.indexOf(marker);
    return found !== -1 && (idx === -1 || found < idx) ? found : idx;
  }, -1);

  if (tocIndex === -1) return { found: false, sections: [] };

  // 解析目录内容（目录后的 2000 字符内）
  const tocContent = content.slice(tocIndex, tocIndex + 2000);
  const sections: Section[] = [];

  // 目录行通常格式：章节标题......页码 或 章节标题 页码
  const lines = tocContent.split('\n');
  for (const line of lines) {
    // 匹配一级标题
    for (const pattern of HEADING_PATTERNS.level1) {
      if (pattern.test(line.trim())) {
        sections.push({
          title: line.trim().replace(/[\.。…]+\d*$/, '').trim(),
          level: 1,
          startIndex: content.indexOf(line.trim()),
        });
        break;
      }
    }
    // 匹配二级标题
    for (const pattern of HEADING_PATTERNS.level2) {
      if (pattern.test(line.trim())) {
        sections.push({
          title: line.trim().replace(/[\.。…]+\d*$/, '').trim(),
          level: 2,
          startIndex: content.indexOf(line.trim()),
          parent: sections.filter(s => s.level === 1).pop()?.title,
        });
        break;
      }
    }
  }

  return { found: sections.length > 0, sections };
}

function detectHeadingPatterns(content: string): {
  sections: Section[]
} {
  const sections: Section[] = [];
  const lines = content.split('\n');
  let currentLevel1: string | undefined;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i].trim();
    if (!line) continue;

    // 检查一级标题
    for (const pattern of HEADING_PATTERNS.level1) {
      if (pattern.test(line) && line.length < 50) {
        currentLevel1 = line;
        sections.push({
          title: line,
          level: 1,
          startIndex: content.indexOf(line),
        });
        break;
      }
    }

    // 检查二级标题
    for (const pattern of HEADING_PATTERNS.level2) {
      if (pattern.test(line) && line.length < 50) {
        sections.push({
          title: line,
          level: 2,
          startIndex: content.indexOf(line),
          parent: currentLevel1,
        });
        break;
      }
    }
  }

  return { sections };
}

### 5.3 章节感知分块

```typescript
// src/lib/section-aware-chunker.ts

export interface ChunkWithSection {
  content: string;
  chunkIndex: number;
  sectionTitle?: string;
  sectionLevel?: number;
  sectionPath?: string[];
}

export function createSectionAwareChunks(
  content: string,
  sections: Section[],
  chunkSize: number = 1000,
  overlap: number = 100
): ChunkWithSection[] {
  const chunks: ChunkWithSection[] = [];

  if (sections.length === 0) {
    // 基础分块（无章节）
    return createBasicChunks(content, chunkSize, overlap);
  }

  // 按章节分块
  for (let i = 0; i < sections.length; i++) {
    const section = sections[i];
    const nextSection = sections[i + 1];

    const sectionStart = section.startIndex;
    const sectionEnd = nextSection?.startIndex ?? content.length;
    const sectionContent = content.slice(sectionStart, sectionEnd);

    // 构建章节路径
    const sectionPath = buildSectionPath(section, sections);

    // 对章节内容进行分块
    const sectionChunks = createBasicChunks(
      sectionContent,
      chunkSize,
      overlap
    );

    for (const chunk of sectionChunks) {
      chunks.push({
        ...chunk,
        chunkIndex: chunks.length,
        sectionTitle: section.title,
        sectionLevel: section.level,
        sectionPath,
      });
    }
  }

  return chunks;
}

function buildSectionPath(section: Section, allSections: Section[]): string[] {
  const path: string[] = [section.title];

  if (section.parent) {
    const parent = allSections.find(
      s => s.title === section.parent && s.level === section.level - 1
    );
    if (parent) {
      path.unshift(parent.title);
      // 递归查找更上层
      if (parent.parent) {
        const grandparent = allSections.find(
          s => s.title === parent.parent && s.level === parent.level - 1
        );
        if (grandparent) {
          path.unshift(grandparent.title);
        }
      }
    }
  }

  return path;
}

function createBasicChunks(
  content: string,
  chunkSize: number,
  overlap: number
): ChunkWithSection[] {
  const chunks: ChunkWithSection[] = [];
  let start = 0;
  let index = 0;

  while (start < content.length) {
    const end = Math.min(start + chunkSize, content.length);
    chunks.push({
      content: content.slice(start, end),
      chunkIndex: index,
    });
    start = end - overlap;
    if (start >= content.length - overlap) break;
    index++;
  }

  return chunks;
}

  mode: 'auto' | 'manual';
  selectedDocuments: Array<{
    documentId: string;
    documentName: string;
    relevanceScore: number;
    selectionReason?: string;
  }>;

export async function selectDocumentsForQuery(
  input: DocumentSelectionInput
): Promise<DocumentSelectionResult> {
  // 1. 如果有手动指定，使用手动模式
  if (input.manualDocumentIds && input.manualDocumentIds.length > 0) {
    return {
      mode: 'manual',
      selectedDocuments: await getDocumentDetails(input.manualDocumentIds),
      availableDocuments: [],
      queryAnalysis: { keywords: [], dataNeeds: [] },
    };
  }

  // 2. 自动选择模式
  const autoConfig = input.autoSelectConfig ?? { enabled: true, maxDocuments: 5 };
  if (!autoConfig.enabled) {
    return {
      mode: 'manual',
      selectedDocuments: [],
      availableDocuments: [],
      queryAnalysis: { keywords: [], dataNeeds: [] },
    };
  }

  // 3. 分析查询意图
  const queryAnalysis = await analyzeQueryIntent(input.question);

  // 4. 执行智能搜索
  const searchResults = await searchDocuments({
    query: input.question,
    filters: {
      year: input.filters?.year ?? queryAnalysis.yearHint,
      docTypes: input.filters?.docTypes,
    },
    options: {
      limit: autoConfig.maxDocuments * 2, // 搜索更多，供用户选择
    },
  });

  // 5. 选择 Top-N 作为默认选中
  const selected = searchResults.documents
    .slice(0, autoConfig.maxDocuments)
    .map(doc => ({
      documentId: doc.documentId,
      documentName: doc.documentName,
      relevanceScore: doc.relevanceScore,
      selectionReason: generateSelectionReason(doc, queryAnalysis),
    }));

  // 6. 其余作为可选
  const available = searchResults.documents
    .slice(autoConfig.maxDocuments)
    .map(doc => ({
      documentId: doc.documentId,
      documentName: doc.documentName,
      relevanceScore: doc.relevanceScore,
    }));

  return {
    mode: 'auto',
    selectedDocuments: selected,
    availableDocuments: available,
    queryAnalysis,
  };
}

function generateSelectionReason(
  doc: any,
  analysis: { keywords: string[]; dataNeeds: string[] }
): string {
  const reasons: string[] = [];

  if (doc.relevanceScore >= 90) {
    reasons.push('高度相关');
  } else if (doc.relevanceScore >= 70) {
    reasons.push('相关度较高');
  }

  if (doc.matchedChunks?.some((c: any) => c.sectionTitle)) {
    const sections = doc.matchedChunks
      .map((c: any) => c.sectionTitle)
      .filter(Boolean);
    if (sections.length > 0) {
      reasons.push(`匹配章节: ${sections[0]}`);
    }
  }

  return reasons.join('; ') || '包含相关信息';
}

## 附录 A: 相关度评分算法

```typescript
采用 **RRF (Reciprocal Rank Fusion)** 算法进行搜索结果排序，不再使用加权公式。

```javascript
/*
 * RRF Score 计算公式
 * score = Σ (1 / (k + rank_i))
 * k = 60 (常数)
 */

// 示例：
// 文档 A: 向量排名 #1, 关键词排名 #10
// Score A = 1/(60+1) + 1/(60+10) = 0.0164 + 0.0143 = 0.0307
