## 1. Executive Summary

This document provides the technical architecture and implementation plan for V3.1 LangGraph 预备重构 (Preparatory Refactoring). The refactoring will restructure existing code to align with LangGraph's architectural patterns while maintaining 100% backward compatibility.

**Design Goals**:
- Zero functional changes (no API behavior changes)
- Gradual, low-risk migration path
- Clear separation of concerns (state, steps, tools)
- Direct mapping to future LangGraph concepts

---

## 2. Architecture Overview

### 2.1 Current Architecture (V2)

```
API Route Handler (一体化)
├── Request parsing
├── Input validation
├── LLM orchestration (inline)
│   ├── Build prompts
│   ├── Call OpenAI
│   ├── Parse response
│   ├── Execute tools
│   └── Calculate confidence
├── Database queries (inline)
└── Response formatting

State: Implicit (local variables)
Tools: Scattered (preset-functions, structured-extraction, etc.)
Types: Duplicated (each route defines own types)
```

**Pain Points**:
- 500+ line route files with mixed concerns
- No reusable workflow steps
- Hard to test individual steps
- Cannot visualize or debug workflows
- Not compatible with LangGraph StateGraph

### 2.2 Target Architecture (V3.1)

```
API Route Handler (薄路由层)
├── Parse request → State
├── Execute Workflow
│   └── WorkflowEngine.run(initialState, steps)
│       ├── Step 1: Validate Input
│       ├── Step 2: Route to Tool
│       ├── Step 3: Execute Tool
│       ├── Step 4: Calculate Confidence
│       └── Step 5: Generate Response
└── Extract response ← State

Workflow Steps (pure functions)
└── (state: S) => Promise<S>

Tool Registry (unified interface)
└── Tool<TInput, TOutput>

State Types (explicit)
└── WorkflowState { input, intermediate, output, meta }
```

**Benefits**:
- Each workflow step is independently testable
- Workflow can be visualized as a graph
- Steps are reusable across routes
- Compatible with LangGraph migration (V3.4)

### 2.3 Architectural Layers

```
┌─────────────────────────────────────────────────┐
│         Layer 1: API Routes (Thin)              │  ← Next.js handlers
│  Parse Request → Run Workflow → Format Response │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│      Layer 2: Workflow Orchestration            │  ← NEW in V3.1
│  WorkflowEngine: state → steps → state          │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│         Layer 3: Step Functions                 │  ← NEW in V3.1
│  Pure functions: (state) => Promise<state>      │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│          Layer 4: Tools & Utilities             │  ← Refactored
│  ToolRegistry, preset-functions, DB queries     │
└─────────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────┐
│       Layer 5: External Services                │  ← Unchanged
│  OpenAI API, Supabase, Storage                  │
└─────────────────────────────────────────────────┘
```

#### 3.1.2 State Definition Pattern

**Design Principle**: Each workflow state follows a consistent structure:

```typescript
interface WorkflowState {
  // 1. Input (from API request)
  input: {
    // User-provided data
  };

  // 2. Intermediate State (workflow progress)
  [stepName]: {
    // Step-specific data
  };

  // 3. Output (for API response)
  output: {
    // Final result
  };

  // 4. Metadata (workflow tracking)
  meta: {
    startTime: number;
    currentStep: string;
    errors: WorkflowError[];
  };
}
```

#### 3.1.3 Example: Financial Analysis State

```typescript
// src/lib/types/workflow-states.ts
```

#### 3.2.3 Example: Financial Analysis Steps

```typescript
// src/lib/workflows/financial-analysis/steps.ts

import type { FinancialAnalysisState } from '@/lib/types/workflow-states';
import type { StepFunction } from '../shared/types';
import { WorkflowError } from '@/lib/errors';
import { toolRegistry } from '@/lib/tools';
import OpenAI from 'openai';

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

/**
 * Step 1: Route user question to appropriate financial function
 * Uses OpenAI function calling to select from preset functions
 */
export const routeToFunction: StepFunction<FinancialAnalysisState> = async (state) => {
  const { question } = state.input;

  // Get financial tools from registry
  const financialTools = toolRegistry.getByCategory('financial');
  const functionDefs = toolRegistry.toOpenAIFunctionDefs(financialTools);

  // Call OpenAI to select function
  const response = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      {
        role: 'system',
        content: '你是财务分析专家，根据用户问题选择合适的财务计算函数。',
      },
      { role: 'user', content: question },
    ],
    tools: functionDefs,
    tool_choice: 'auto',
  });

  const toolCall = response.choices[0].message.tool_calls?.[0];
  const selectedFunction = toolCall?.function.name || null;

  return {
    ...state,
    routing: {
      selectedFunction,
      alternatives: financialTools.map(t => t.name),
      confidence: selectedFunction ? 0.85 : 0.2,
    },
    meta: {
      ...state.meta,
      currentStep: 'routeToFunction',
    },
  };
};

/**
 * Step 2: Query financial data from database
 * Retrieves metric values needed for calculation inputs
 */
export const queryFinancialData: StepFunction<FinancialAnalysisState> = async (state) => {
  const { selectedFunction } = state.routing;
  const { documentId, uploadedDocument } = state.input;

  if (!selectedFunction) {
    throw new WorkflowError('NO_FUNCTION_SELECTED', 'Cannot query data without function');
  }

  // Get tool to determine required inputs
  const tool = toolRegistry.get(selectedFunction);
  if (!tool) {
    throw new WorkflowError('TOOL_NOT_FOUND', `Function ${selectedFunction} not found`);
  }

  const requiredInputs = tool.metadata?.requiredInputs || [];

  // Query database for metrics
  // (Actual DB query logic moved to separate utility)
  const { availableMetrics, queryResults } = await fetchMetricsFromDatabase({
    documentId,
    uploadedDocument,
    requiredInputs,
  });

  const missingMetrics = requiredInputs.filter(
    input => !availableMetrics.includes(input)
  );

  return {
    ...state,
    dataQuery: {
      requiredInputs,
      availableMetrics,
      missingMetrics,
      queryResults,
    },
    meta: {
      ...state.meta,
      currentStep: 'queryFinancialData',
    },
  };
};

/**
 * Step 3: Execute financial calculation
 * Calls the selected tool with queried data
 */
export const executeCalculation: StepFunction<FinancialAnalysisState> = async (state) => {
  const { selectedFunction } = state.routing;
  const { queryResults, missingMetrics } = state.dataQuery;

  if (!selectedFunction) {
    throw new WorkflowError('NO_FUNCTION_SELECTED', 'Cannot calculate without function');
  }

  if (missingMetrics.length > 0) {
    // Return state with null result (will trigger low confidence)
    return {
      ...state,
      calculation: {
        functionName: selectedFunction,
        inputs: queryResults,
        result: null,
        formula: '',
        unit: '',
      },
      meta: {
        ...state.meta,
        currentStep: 'executeCalculation',
        errors: [
          ...state.meta.errors,
          new WorkflowError('INSUFFICIENT_DATA', `Missing: ${missingMetrics.join(', ')}`),
        ],
      },
    };
  }

  // Execute tool
  const tool = toolRegistry.get(selectedFunction)!;
  const result = await tool.execute(queryResults);

  return {
    ...state,
    calculation: {
      functionName: selectedFunction,
      inputs: queryResults,
      result: result.value,
      formula: result.formula,
      unit: result.unit,
    },
    meta: {
      ...state.meta,
      currentStep: 'executeCalculation',
    },
  };
};

/**
 * Step 4: Evaluate confidence score
 * Calculates confidence based on data availability and result quality
 */
export const evaluateConfidence: StepFunction<FinancialAnalysisState> = async (state) => {
  const { availableMetrics, requiredInputs, missingMetrics } = state.dataQuery;
  const { result } = state.calculation;

  const factors = [
    {
      factor: 'data_availability',
      weight: 0.4,
      score: availableMetrics.length / requiredInputs.length,
    },
    {
      factor: 'calculation_success',
      weight: 0.3,
      score: result !== null ? 1.0 : 0.0,
    },
    {
      factor: 'routing_confidence',
      weight: 0.3,
      score: state.routing.confidence,
    },
  ];

  const totalScore = factors.reduce((sum, f) => sum + f.weight * f.score, 0);
  const threshold = 0.7;

  return {
    ...state,
    confidence: {
      score: totalScore,
      factors,
      threshold,
      passed: totalScore >= threshold,
    },
    meta: {
      ...state.meta,
      currentStep: 'evaluateConfidence',
    },
  };
};

/**
 * Step 5: Generate final response
 * Formats result into user-facing answer
 */
export const generateResponse: StepFunction<FinancialAnalysisState> = async (state) => {
  const { passed } = state.confidence;
  const { result, formula, inputs, unit } = state.calculation;
  const { missingMetrics } = state.dataQuery;

  if (!passed) {
    return {
      ...state,
      output: {
        answer: '数据不足，无法完成计算',
        warnings: [
          `缺少以下指标: ${missingMetrics.join(', ')}`,
        ],
      },
      meta: {
        ...state.meta,
        currentStep: 'generateResponse',
        endTime: Date.now(),
      },
    };
  }

  return {
    ...state,
    output: {
      answer: `计算结果: ${result}${unit}`,
      calculation: {
        result: result!,
        formula,
        inputs,
        unit,
      },
      citations: Object.entries(inputs).map(([metric, value]) => ({
        source: '财务数据',
        metric,
        value,
      })),
    },
    meta: {
      ...state.meta,
      currentStep: 'generateResponse',
      endTime: Date.now(),
    },
  };
};
```

#### 3.2.4 Workflow Orchestrator

```typescript
// src/lib/workflows/financial-analysis/index.ts

import type { FinancialAnalysisState } from '@/lib/types/workflow-states';
import * as steps from './steps';

/**
 * Financial Analysis Workflow
 * Executes a sequence of steps to answer financial questions
 */
export async function runFinancialAnalysisWorkflow(
  input: FinancialAnalysisState['input']
): Promise<FinancialAnalysisState> {
  // Initialize state
  let state: FinancialAnalysisState = {
    input,
    routing: { selectedFunction: null, alternatives: [], confidence: 0 },
    dataQuery: { requiredInputs: [], availableMetrics: [], missingMetrics: [], queryResults: {} },
    calculation: { functionName: '', inputs: {}, result: null, formula: '', unit: '' },
    confidence: { score: 0, factors: [], threshold: 0.7, passed: false },
    output: { answer: '' },
    meta: {
      startTime: Date.now(),
      currentStep: 'init',
      errors: [],
    },
  };

  // Execute steps sequentially
  try {
    state = await steps.routeToFunction(state);
    state = await steps.queryFinancialData(state);
    state = await steps.executeCalculation(state);
    state = await steps.evaluateConfidence(state);
    state = await steps.generateResponse(state);
  } catch (error) {
    // Error handling (Phase E will enhance this)
    state.meta.errors.push(error as WorkflowError);
    state.output.answer = '处理过程中发生错误';
  }

  return state;
}
```

```typescript
// src/lib/tools/types.ts

import { z } from 'zod';

// Tool categories
export type ToolCategory =
  | 'financial'      // Calculations
  | 'search'         // Database/vector search
  | 'extraction'     // Document parsing
  | 'storage'        // File operations
  | 'validation';    // Data validation

// Core tool interface
export interface Tool<TInput = unknown, TOutput = unknown> {
  // Identity
  name: string;
  displayName: string;
  description: string;
  category: ToolCategory;

  // Schema (Zod for validation + LangGraph compatibility)
  inputSchema: z.ZodSchema<TInput>;
  outputSchema: z.ZodSchema<TOutput>;

  // Execution
  execute: (input: TInput) => Promise<TOutput>;

  // Metadata
  metadata?: {
    requiredInputs?: string[];    // For financial tools
    timeout?: number;             // Max execution time (ms)
    retryable?: boolean;          // Can retry on failure
    requiresAuth?: boolean;       // Needs admin password
    cost?: 'free' | 'paid';       // OpenAI API cost
  };
}

// Tool execution result wrapper
export interface ToolResult<T> {
  success: boolean;
  data?: T;
  error?: {
    code: string;
    message: string;
  };
  executionTime: number;
}
```

#### 3.3.3 Tool Registry Implementation

```typescript
// src/lib/tools/registry.ts

import type { Tool, ToolCategory } from './types';
import type { ChatCompletionTool } from 'openai/resources/chat/completions';

export class ToolRegistry {
  private tools = new Map<string, Tool>();

  /**
   * Register a tool
   */
  register<TInput, TOutput>(tool: Tool<TInput, TOutput>): void {
    if (this.tools.has(tool.name)) {
      throw new Error(`Tool '${tool.name}' already registered`);
    }
    this.tools.set(tool.name, tool as Tool);
  }

  /**
   * Get tool by name
   */
  get(name: string): Tool | undefined {
    return this.tools.get(name);
  }

  /**
   * Get all tools in category
   */
  getByCategory(category: ToolCategory): Tool[] {
    return Array.from(this.tools.values()).filter(
      tool => tool.category === category
    );
  }

  /**
   * Get all tool names
   */
  listNames(): string[] {
    return Array.from(this.tools.keys());
  }

  /**
   * Convert tools to OpenAI function definitions
   */
  toOpenAIFunctionDefs(tools?: Tool[]): ChatCompletionTool[] {
    const targetTools = tools || Array.from(this.tools.values());

    return targetTools.map(tool => ({
      type: 'function' as const,
      function: {
        name: tool.name,
        description: tool.description,
        parameters: zodToJsonSchema(tool.inputSchema),
      },
    }));
  }

  /**
   * Execute tool by name (with error handling)
   */
  async execute<TInput, TOutput>(
    name: string,
    input: TInput
  ): Promise<ToolResult<TOutput>> {
    const startTime = Date.now();
    const tool = this.tools.get(name);

    if (!tool) {
      return {
        success: false,
        error: {
          code: 'TOOL_NOT_FOUND',
          message: `Tool '${name}' not found`,
        },
        executionTime: 0,
      };
    }

    try {
      // Validate input
      const validatedInput = tool.inputSchema.parse(input);

      // Execute
      const result = await tool.execute(validatedInput);

      // Validate output
      const validatedOutput = tool.outputSchema.parse(result);

      return {
        success: true,
        data: validatedOutput as TOutput,
        executionTime: Date.now() - startTime,
      };
    } catch (error) {
      return {
        success: false,
        error: {
          code: error instanceof z.ZodError ? 'VALIDATION_ERROR' : 'EXECUTION_ERROR',
          message: error instanceof Error ? error.message : 'Unknown error',
        },
        executionTime: Date.now() - startTime,
      };
    }
  }
}

// Singleton instance
export const toolRegistry = new ToolRegistry();

// Helper: Convert Zod schema to JSON Schema (for OpenAI)
function zodToJsonSchema(schema: z.ZodSchema): Record<string, unknown> {
  // Simplified - production would use @anatine/zod-to-openapi
  // For V3.1, we can manually define schemas
  return {
    type: 'object',
    properties: {},
    required: [],
  };
}
```

```typescript
// src/lib/tools/search-tools.ts

import { z } from 'zod';
import { toolRegistry } from './registry';
import { performHybridSearch } from '../hybrid-search';

// Hybrid Search Tool
toolRegistry.register({
  name: 'hybrid_search',
  displayName: '混合搜索',
  description: '使用向量相似度和关键词匹配进行合规文档搜索',
  category: 'search',

  inputSchema: z.object({
    query: z.string(),
    keywords: z.array(z.string()).optional(),
    limit: z.number().default(10),
    minRelevance: z.number().default(0.6),
  }),

  outputSchema: z.object({
    results: z.array(z.object({
      chunkId: z.string(),
      content: z.string(),
      relevance: z.number(),
      source: z.string(),
      metadata: z.record(z.unknown()),
    })),
    totalResults: z.number(),
  }),

  execute: async (input) => {
    const results = await performHybridSearch({
      query: input.query,
      keywords: input.keywords,
      limit: input.limit,
    });

    return {
      results: results
        .filter(r => r.relevance >= input.minRelevance)
        .map(r => ({
          chunkId: r.id,
          content: r.content,
          relevance: r.relevance,
          source: r.document_name,
          metadata: r.metadata || {},
        })),
      totalResults: results.length,
    };
  },

  metadata: {
    timeout: 10000,
    retryable: true,
    requiresAuth: false,
    cost: 'paid', // OpenAI embedding API
  },
});
```

```typescript
// src/lib/errors/base.ts

/**
 * Base error class for all workflow errors
 * Provides structure for LangGraph conditional edge error handling
 */
export abstract class WorkflowError extends Error {
  // Error code (stable, machine-readable)
  abstract readonly code: string;

  // Recoverable flag (can retry with different strategy)
  abstract readonly recoverable: boolean;

  // HTTP status code for API errors
  readonly httpStatus: number = 500;

  constructor(
    message: string,
    public readonly context?: Record<string, unknown>
  ) {
    super(message);
    this.name = this.constructor.name;
    Error.captureStackTrace(this, this.constructor);
  }

  /**
   * Serialize for API response
   */
  toJSON() {
    return {
      error: this.name,
      code: this.code,
      message: this.message,
      recoverable: this.recoverable,
      context: this.context,
      httpStatus: this.httpStatus,
    };
  }

  /**
   * Check if error is recoverable
   */
  isRecoverable(): boolean {
    return this.recoverable;
  }
}
```

#### 3.5.6 Error Handler Utility

```typescript
// src/lib/errors/index.ts

export * from './base';
export * from './tool-errors';
export * from './workflow-errors';
export * from './api-errors';

import { WorkflowError } from './base';
import { InvalidRequestError } from './api-errors';

/**
 * Convert unknown error to WorkflowError
 */
export function toWorkflowError(error: unknown): WorkflowError {
  if (error instanceof WorkflowError) {
    return error;
  }

  if (error instanceof Error) {
    return new InvalidRequestError(error.message, {
      originalError: error.name,
      stack: error.stack,
    });
  }

  return new InvalidRequestError('Unknown error occurred', {
    error: String(error),
  });
}

/**
 * Format error for API response
 */
export function formatErrorResponse(error: WorkflowError) {
  return {
    error: error.code,
    message: error.message,
    recoverable: error.recoverable,
    context: error.context,
  };
}
```

### 5.2 Example: V3.4 Migration Preview

**V3.1 Code (after refactoring)**:

**V3.4 Code (with LangGraph)**:
```typescript
import { StateGraph } from '@langchain/langgraph';
import type { FinancialAnalysisState } from '@/lib/types';
import * as steps from './steps';

// Define graph
const workflow = new StateGraph<FinancialAnalysisState>({
  channels: { ... },
})
  .addNode('route', steps.routeToFunction)
  .addNode('query', steps.queryData)
  .addNode('calculate', steps.calculate)
  .addEdge('route', 'query')
  .addEdge('query', 'calculate')
  .addConditionalEdges('calculate', (state) => {
    return state.confidence.passed ? 'respond' : 'retry';
  });

// Compile and run
const app = workflow.compile();
const result = await app.invoke(input);
```
