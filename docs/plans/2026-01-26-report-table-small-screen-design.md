# 报表表格小屏可读性优化设计

日期：2026-01-26

## 背景与问题
当前报表页面在小屏幕下，表格会被视口压缩为窄列，导致数值换行、阅读困难。用户期望的体验与 `/documents` 页面一致：保留完整列布局，通过横向滚动查看，不引入额外提示或交互。

## 目标
- 小屏下保持桌面式表格布局与列顺序不变。
- 允许横向滚动以查看所有列，提升数值可读性。
- 不改变报表数据、计算、折叠逻辑或文案。

## 非目标
- 不将表格改为卡片式展示或分段折叠。
- 不新增滚动提示文案或交互按钮。
- 不调整指标解释与格式化逻辑。

## 方案概述
- 保留 `ReportSection` 中现有表格与容器结构。
- 确保外层容器使用 `overflow-x-auto`。
- 为表格添加固定最小宽度（`min-w-[...px]`），避免被小屏压缩。
- 对数值类列（同比、环比、数值）添加 `whitespace-nowrap`，防止数字断行。
- 文本列（指标名、说明）保持原有换行策略。

## 影响范围
- 仅影响 `src/components/reports/ReportSection.tsx` 的布局类名。
- 不涉及 API、数据模型、报表生成或提示文案变更。

## 验证方式
- 单元测试：在 `tests/unit/reports/report-section.test.tsx` 中断言表格最小宽度类与数值列 `whitespace-nowrap` 类存在。
- 手动回归：使用小屏尺寸（如 375px）检查横向滚动可用、列完整显示。
