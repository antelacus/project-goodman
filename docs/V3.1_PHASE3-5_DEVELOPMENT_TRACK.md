#### 1. Financial Analysis Workflow (完成)

**目录结构**:
```
src/lib/workflows/financial-analysis/
├── steps.ts  (658 行) - 5 个步骤函数
└── index.ts  (117 行) - 工作流编排器
```

**步骤函数**:

1. **routeToFunction** - 路由问题到合适的函数
   - 调用 OpenAI 选择 preset function 或 get_financial_metric
   - 更新 `state.routing`

2. **queryData** - 查询财务数据
   - 从数据库查询所需指标
   - 处理 fuzzy matching (模糊匹配)
   - 更新 `state.dataQuery`

3. **executeCalculation** - 执行计算
   - 使用 preset function 计算或执行数据对比
   - 更新 `state.calculation`

4. **evaluateConfidence** - 评估置信度
   - 计算综合置信度分数
   - 检查是否通过阈值
   - 更新 `state.confidence`

5. **generateResponse** - 生成自然语言响应
   - 调用 OpenAI 生成解释
   - 构建最终输出
   - 更新 `state.output`

**工作流编排器**:
```typescript
export async function runFinancialAnalysisWorkflow(
  input: FinancialAnalysisState["input"]
): Promise<FinancialAnalysisState> {
  let state = initializeState(input);

  state = await steps.routeToFunction(state);
  if (!state.routing.selectedFunction) {
    return await steps.generateResponse(state);
  }

  state = await steps.queryData(state);
  if (state.dataQuery.missingMetrics.length > 0) {
    return await steps.generateResponse(state);
  }

  state = await steps.executeCalculation(state);
  state = await steps.evaluateConfidence(state);

  if (!state.confidence.passed) {
    return await steps.generateResponse(state);
  }

  return await steps.generateResponse(state);
}
```

**步骤函数**:

1. **performHybridSearch** - 混合搜索 (向量 + 关键词)
   - 提取关键词进行结构化搜索
   - 生成 embedding 进行语义搜索
   - 合并并排序搜索结果
   - 更新 `state.search`

2. **generateGuidance** - 生成合规指导
   - 调用 OpenAI 生成指导意见
   - 支持工具调用 (query_financial_data, calculate_financial_metric)
   - 处理多轮工具调用 (最多 5 轮)
   - 更新 `state.reasoning` 和 `state.toolExecution`

3. **findRelatedArticles** - 查找相关条款
   - 基于引用的法规查找相关条款
   - 排除已在主引用中的条款
   - 更新 `state.relatedArticles`

4. **evaluateConfidence** - 评估置信度
   - 计算语义相似度、引用数量、上下文相关性
   - 检查是否通过阈值 (0.6)
   - 更新 `state.confidence`

5. **generateResponse** - 生成最终响应
   - 构建完整输出结构
   - 包含指导、引用、相关条款、计算结果
   - 更新 `state.output`

**工作流编排器**:
```typescript
export async function runGuidanceChatWorkflow(
  input: GuidanceChatState["input"]
): Promise<GuidanceChatState> {
  let state = initializeState(input);

  state = await steps.performHybridSearch(state);
  if (state.search.combinedResults.length === 0) {
    return earlyExitNoResults(state);
  }

  state = await steps.generateGuidance(state);
  state = await steps.findRelatedArticles(state);
  state = await steps.evaluateConfidence(state);
  state = await steps.generateResponse(state);

  return state;
}
```

## 架构决策记录

### ADR-001: 步骤函数签名

**决策**: 所有步骤函数使用签名 `(state: S) => Promise<S>`

**理由**:
- 纯函数，易于测试
- 状态不可变，利于调试
- 与 LangGraph Node 函数签名一致

### ADR-002: 错误处理策略

**决策**: 错误在工作流编排器层统一处理

**理由**:
- 步骤函数抛出错误，编排器捕获
- 更符合 LangGraph 条件边模式
- 集中化错误处理逻辑

### ADR-003: 置信度评估位置

**决策**: 置信度评估作为独立步骤

**理由**:
- 可复用（多个工作流共享）
- 可配置（不同工作流不同阈值）
- 明确的决策点（通过/不通过）
