## 概述

V3.6 旨在消除代码重复，统一工具架构和 Agent Graph，提供更现代的交互体验。

核心目标：

1. **统一 Agent 架构**: 提取核心节点逻辑，统一工具注册表，构建单一 UnifiedAgentGraph。
2. **实时反馈**: 实现 WebSocket (或 SSE) 流式响应机制。
3. **统一 UI**: 实现单页应用式的对话界面，整合现有三个模块的功能。

## Phase A: 统一 Agent 架构 (V3.6a) ✅

**状态**: ✅ 已完成
**完成日期**: 2025-12-23

### A1: 核心节点提取 ✅

**文件**: `src/lib/workflows/core/nodes/*.ts`

实现通用的、可复用的工作流节点：

- `loadMemoryNode` (`load-memory.ts`): 加载历史消息，支持 `initialMessageCount`。
- `agentLoopNode` (`agent-loop.ts`): 通用 Agent 循环，负责调用 LLM 和处理工具调用请求。
- `toolExecutorNode` (`tool-executor.ts`): 基于 `ToolRegistry` 的通用工具执行器。
- `saveMemoryNode` (`save-memory.ts`): 仅保存增量消息的内存持久化节点。
- `generateResponseNode` (`generate-response.ts`): 提取最终响应。

### A2: 工具系统重组 ✅

**目录**: `src/lib/tools/`

实现扁平化的工具架构：

- 创建 `compliance` (合规) 和 `extraction` (提取) 目录。
- 实现工具包装器:
  - `search_regulations` (`compliance/search-regulations.ts`)
  - `search_documents` (`compliance/search-documents.ts`)
  - `extract_document` (`extraction/extract-document.ts`)
- 更新 `ToolRegistry` 支持幂等注册。
- `index.ts` 导出 `registerUnifiedTools()`。

### A3: Unified Agent Graph ✅

**目录**: `src/lib/workflows/unified/`

实现统一 Agent 工作流：

- `state.ts`: 定义 `UnifiedAgentState`。
- `prompts.ts`: 定义 `UNIFIED_AGENT_SYSTEM_PROMPT`。
- `graph.ts`: 使用 LangGraph 组装核心节点，实现 `UnifiedAgentGraph`。
- `nodes.ts`: 包装器节点，确保工具注册。

### A4: API 与 数据库 ✅

**文件**:

- `src/app/api/chat/route.ts`: 新增 POST 接口，调用 Unified Agent。
- `supabase/migrations/20251224_add_unified_workflow.sql`: 更新数据库约束，支持 `'unified'` 工作流类型。
- `scripts/verify-unified-agent.ts`: 验证脚本。
