| **指标/项目名称**        | **计算公式**                                                 | **类别**       | **应用体系**       |
| ------------------------ | ------------------------------------------------------------ | -------------- | ------------------ |
| **营运资本**             | $\text{流动资产} - \text{流动负债}$ 或 $\text{长期资本} - \text{长期资产}$ 1 | 短期偿债能力   | 传统财报体系       |
| **流动比率**             | $\frac{\text{流动资产}}{\text{流动负债}}$ 2                  | 短期偿债能力   | 传统财报体系       |
| **速动比率**             | $\frac{\text{速动资产}}{\text{流动负债}}$ (速动资产 = 货币资金+交易性金融资产+各种应收款项) 3 | 短期偿债能力   | 传统财报体系       |
| **现金比率**             | $\frac{\text{货币资金}}{\text{流动负债}}$ 4                  | 短期偿债能力   | 传统财报体系       |
| **现金流量比率**         | $\frac{\text{经营活动现金流量净额}}{\text{流动负债(期末数)}}$ 5 | 短期偿债能力   | 传统财报体系       |
| **资产负债率**           | $\frac{\text{总负债}}{\text{总资产}} \times 100\%$ 6         | 长期偿债能力   | 传统财报体系       |
| **产权比率**             | $\frac{\text{总负债}}{\text{股东权益}}$ 7                    | 长期偿债能力   | 传统财报体系       |
| **权益乘数**             | $\frac{\text{总资产}}{\text{股东权益}} = 1 + \text{产权比率} = \frac{1}{1-\text{资产负债率}}$ 8 | 长期偿债能力   | 传统财报体系       |
| **长期资本负债率**       | $\frac{\text{非流动负债}}{\text{非流动负债} + \text{股东权益}} \times 100\%$ 9 | 长期偿债能力   | 传统财报体系       |
| **利息保障倍数**         | $\frac{\text{息税前利润}}{\text{利息支出}}$ (息税前利润 = 净利润+所得税+利息费用) 10 | 长期偿债能力   | 传统财报体系       |
| **现金流量利息保障倍数** | $\frac{\text{经营活动现金流量净额}}{\text{利息支出}}$ 11     | 长期偿债能力   | 传统财报体系       |
| **现金流量与负债比率**   | $\frac{\text{经营活动现金流量净额}}{\text{负债总额(期末数)}} \times 100\%$ 12 | 长期偿债能力   | 传统财报体系       |
| **总资产周转次数**       | $\frac{\text{营业收入}}{\text{总资产}}$ 13                   | 营运能力       | 传统财报体系       |
| **总资产周转天数**       | $\frac{365}{\text{总资产周转次数}}$ 或 $\frac{365 \times \text{总资产}}{\text{营业收入}}$ 14 | 营运能力       | 传统财报体系       |
| **应收账款周转次数**     | $\frac{\text{营业收入}}{\text{应收账款}}$ 15                 | 营运能力       | 传统财报体系       |
| **存货周转次数**         | $\frac{\text{营业收入(或营业成本)}}{\text{存货}}$ 16         | 营运能力       | 传统财报体系       |
| **营业净利率**           | $\frac{\text{净利润}}{\text{营业收入}} \times 100\%$ 17      | 盈利能力       | 传统财报体系       |
| **总资产净利率**         | $\frac{\text{净利润}}{\text{总资产}} \times 100\%$ 18        | 盈利能力       | 传统财报体系       |
| **权益净利率 (ROE)**     | $\frac{\text{净利润}}{\text{股东权益}} \times 100\%$ 19      | 盈利能力       | 传统财报体系       |
| **市盈率 (P/E)**         | $\frac{\text{每股市价}}{\text{每股收益}}$ 20                 | 市价比率       | 传统财报体系       |
| **市净率 (P/B)**         | $\frac{\text{每股市价}}{\text{每股净资产}}$ 21               | 市价比率       | 传统财报体系       |
| **市销率 (P/S)**         | $\frac{\text{每股市价}}{\text{每股营业收入}}$ 22             | 市价比率       | 传统财报体系       |
| **杜邦分析核心公式**     | $\text{权益净利率} = \text{营业净利率} \times \text{总资产周转次数} \times \text{权益乘数}$ 23 | 综合分析       | 传统财报体系       |
| **净经营资产**           | $\text{经营资产} - \text{经营负债} = \text{净负债} + \text{股东权益}$ 24 | 资产负债表重构 | **管理用财报体系** |
| **净负债**               | $\text{金融负债} - \text{金融资产}$ 25                       | 资产负债表重构 | **管理用财报体系** |
| **税前经营利润**         | $\text{营业收入} - \text{营业成本} - \text{税金及附加} - \text{销售/管理费用}$ (不含利息) 26 | 利润表重构     | **管理用财报体系** |
| **税后经营净利润**       | $\text{税前经营利润} \times (1 - \text{所得税税率})$ 27      | 利润表重构     | **管理用财报体系** |
| **税后利息费用**         | $\text{利息费用} \times (1 - \text{所得税税率})$ 28          | 利润表重构     | **管理用财报体系** |
| **营业现金毛流量**       | $\text{税后经营净利润} + \text{折旧与摊销}$ 29               | 现金流量表重构 | **管理用财报体系** |
| **营业现金净流量**       | $\text{营业现金毛流量} - \text{经营营运资本增加}$ 30         | 现金流量表重构 | **管理用财报体系** |
| **实体现金流量**         | $\text{营业现金净流量} - \text{资本支出} = \text{税后经营净利润} - \text{净经营资产增加}$ 31313131 | 现金流量表重构 | **管理用财报体系** |
| **融资现金流量**         | $\text{债务现金流量} + \text{股权现金流量} = \text{实体现金流量}$ 32 | 现金流量表重构 | **管理用财报体系** |
| **净经营资产净利率**     | $\frac{\text{税后经营净利润}}{\text{净经营资产}}$ 33         | 盈利能力       | **管理用财报体系** |
| **税后利息率**           | $\frac{\text{税后利息费用}}{\text{净负债}}$ 34               | 偿债/成本      | **管理用财报体系** |
| **净财务杠杆**           | $\frac{\text{净负债}}{\text{股东权益}}$ 35                   | 杠杆水平       | **管理用财报体系** |
| **管理用ROE核心公式**    | $\text{权益净利率} = \text{净经营资产净利率} + (\text{净经营资产净利率} - \text{税后利息率}) \times \text{净财务杠杆}$ 36 | 综合分析       | **管理用财报体系** |
| **融资总需求**           | $\text{净经营资产销售百分比} \times \text{营业收入增加额}$ 37 | 资金预测       | 销售百分比法       |
| **外部融资额**           | $\text{融资总需求} - \text{可动用金融资产} - \text{预计增加的留存收益}$ 38 | 资金预测       | 销售百分比法       |
| **内含增长率**           | 当外部融资为0时的增长率。公式：$0 = \text{净经营资产销售百分比} - [\frac{1+g}{g}] \times \text{预计营业净利率} \times \text{利润留存率}$ 39 | 增长率预测     | 财务预测           |
| **可持续增长率**         | $\frac{\text{期初权益净利率} \times \text{利润留存率}}{1}$ (基于期初权益) 或 $\frac{\text{期末权益净利率} \times \text{利润留存率}}{1 - \text{期末权益净利率} \times \text{利润留存率}}$ 40404040 | 增长率预测     | 财务预测           |
