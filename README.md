## 产品介绍

Project Goodman 是一款面向企业会计部门的 AI 财务助手。通过自然语言交互，帮助财务人员快速完成财务指标计算、合规查询、报告生成等日常工作。

**核心理念**：

- **对话即操作**：无需学习复杂菜单，用自然语言描述需求，AI 自动调用合适的工具
- **过程透明**：每一步计算都可展开查看，数据来源可追溯，支持人工核验
- **专业可靠**：采用确定性公式计算财务指标，避免 AI 幻觉

**适用对象**：企业会计部门财务人员、财务分析师、审计人员

---

## 功能概览

| 功能 | 描述 |
|------|------|
| **指标查询**   | 从数据库查询财务指标（资产、负债、利润、现金流等） |
| **比率查询**   | 进行财务比率计算（流动比率、利润率等），支持多期对比 |
| **自定义计算** | 进行自定义计算（营销费用占收入比例、自定义公式等），支持多期对比 |
| **文档检索**   | 从数据库搜索财务报告、税务法规、会计准则和公司内部文档中的内容 |
| **信息提取**   | 属于“快捷操作”，从用户上传文档中结构化提取财务相关信息 |
| **生成报告**   | 属于“高级工具”，根据用户需求结合上述能力生成财务分析综合报告 |

“指标查询”、“比率查询”、“自定义计算”、“文档检索”功能使用自然语言对话实现，“快捷操作”和“高级工具”有单独入口。

## 用户角色

### 访客 (Guest)

无需注册即可体验系统核心功能。

**可用功能**：

- 智能对话（每小时 20 次）
- 文档上传（每小时 2 次）
- 快捷操作（每小时 2 次）
- 高级工具（每小时 1 次）

**限制**：

- 首次进入系统自动分配访客角色，闲置1小时后所有数据清除。
- 访客只能查看数据库中的文档和上传的文档，不能管理文档（1小时不活跃后自动删除访客上传的文档）。

**如何体验**：直接访问 [在线演示](https://goodman.antelacus.com)，系统会自动分配访客会话。

---

### 用户（User）

当前项目尚未开放注册，无用户角色。

---

### 管理员 (Admin)

管理员拥有管理权限。

**额外功能**：

- 上传财务数据到数据库（供所有用户查询）
- 上传各类文档到知识库（供所有用户查询）
- 管理数据库中的文档（修改属性，重命名，删除等）

## 功能详解

### 智能对话

在工作台与 AI 助手对话，它能理解你的财务问题并自动完成分析。

**使用示例**：

- "帮我计算 2024 年的流动比率"
- "分析一下公司的偿债能力"
- "对比 2023 和 2024 年的 ROE 变化"

**过程透明化**：

每次 AI 回答后，你可以点击「查看过程」展开详细步骤：

- 🤔 AI 的思考过程
- 🔧 调用了哪些工具
- 📄 数据来自哪些文档
- 📊 具体计算公式和数值

这让你可以核验每一步，确保结果准确可信。

**支持的财务分析**：

- 流动性分析（流动比率、速动比率、现金比率等）
- 偿债能力分析（资产负债率、利息保障倍数等）
- 盈利能力分析（ROE、ROA、净利润率等）
- 运营效率分析（存货周转率、应收账款周转率等）
- 杜邦分析（完整分解）

---

### 信息提取

属于“快捷操作”，从财务相关文件中自动提取结构化数据。

**支持的文件格式**：

- PDF 文档
- 图片（PNG、JPG、WEBP）
- Excel 表格（XLSX）

**提取内容**：

Invoices (发票):

- 发票号码, 发票代码, 开票日期
- 购买方/销售方名称, 纳税人识别号
- 金额, 税额, 价税合计
- 商品/服务名称, 规格型号, 数量, 单价

Contracts (合同):

- 合同编号, 签订日期, 有效期
- 甲方/乙方名称
- 合同金额, 付款方式, 付款条件
- 主要条款摘要

Financial Statements (财务报表):

- 报表名称, 报告期间, 编制单位
- 所有科目名称及金额
- 合计数, 期初/期末数

Receipts (收据):

- 收据编号, 日期
- 付款人/收款人
- 金额, 用途

**如何使用**：

1. 点击侧边栏中的「信息提取」按钮
2. 上传财务相关文件
3. AI 自动识别并提取数据
4. 可自由复制标题、内容或同时复制标题和内容

---

### 报告生成

属于“高级工具”，自动生成结构化的综合财务分析报告。

**报告内容**：

- 执行摘要（关键发现、风险警示、建议）
- 流动性分析章节
- 偿债能力分析章节
- 盈利能力分析章节
- 运营效率分析章节
- 综合评价与建议

**如何生成**：

1. 点击对话框的的「高级工具」按钮
2. 选择「生成报告」
3. 在对话中配置报告参数（指标、年份、是否对比等）
4. 等待生成完成，查看报告
5. 可导出为 DOCX 保存
6. 可继续在对话中针对生成的报告进行查询

**实时进度**：生成过程中可以看到实时进度，了解当前正在分析哪个章节。

## 开发者快速开始

### 技术栈概览

- Next.js 15 / React 19 / TypeScript
- Supabase (Postgres) + Redis
- LangGraph + OpenAI
- Tailwind CSS
- Vitest + Playwright + Lighthouse CI + axe + autocannon
- Sentry + UptimeRobot

### 环境变量与本地运行

1. 安装依赖：`npm install`
2. 复制环境变量：`cp .env.example .env.local`
3. 必填配置：
   - `OPENAI_API_KEY`
   - `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_PASSWORD`
   - `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD`（开发环境可用 `REDIS_DISABLED=true` 关闭）
4. 启动开发：`npm run dev`，访问 `http://localhost:3000`

### 测试与门禁

- 基础质量：`npm run lint` / `npm run build` / `npm run test -- --run`
- 覆盖率：`npm run test:coverage`
- 性能基线：`npm run test:perf`（需 `PERF_TEST_MODE=true`，并先启动本地服务）
- Lighthouse：`npm run test:lighthouse`（基线对比用 `npm run test:lighthouse:gate`）
- A11y：`npm run test:a11y`

提示：门禁目标地址可通过 `PERF_BASE_URL` / `LHCI_BASE_URL` / `A11Y_BASE_URL` 指定；`QUALITY_GATES_STRICT=false` 可降级为警告。
